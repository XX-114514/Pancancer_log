# Run 20260906 communication evidence chain

## Status

Completed manuscript-facing snapshot on 2026-09-06.

## Scope

This run links frozen V5 CoVarNet modules to per-sample LIANA communication,
Visium/CosMx spatial evidence, receiver-state associations and TCGA/ICI clinical
proxies. It does not rerun the communication analysis on V7.

## Outputs retained in Git

- Two narrative reports.
- Four aggregate source tables.
- Ten PDF/PNG figure pairs and one combined PNG review sheet.

Cell-level CosMx tables, patient-level matrices, full LIANA event tables and
workstation-specific scripts remain external.

## Main interpretation

The curated desmoplasia/myCAF signature is supported as a fibroblast/myofibroblast
program, while the frozen CM07 projection contains epithelial composition signal
and should not be used as a generic fibrosis readout. Immune/TLS associations are
cancer- and treatment-context dependent. Bulk ligand-receptor co-expression is a
proxy and does not recreate directional cell-cell communication.
