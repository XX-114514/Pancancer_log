# 患者级程序分布读出的人工设计实验

本次只使用人工随机数组，无真实生物输入、患者记录、模型权重或原生下载。目标是检验“均值不足是否值得成为新问题”与“来源内外关联是否可混为一谈”，不是挑选真实数据中P值最小的方法。

## 方法与执行

通用代码：[simulate_patient_program_readouts_v1.py](../scripts/simulate_patient_program_readouts_v1.py)。本机Python3.13.9、NumPy2.4.1。每次32个独立人工患者、两组等样本来源；每类型/患者50、200、1000细胞；四场景：来源内独立、只有来源均值移动、整个群体活动协同、仅5%高活跃细胞的强度协同。独立患者背景偏移保留。

五个读出为均值、q75、q95、q99、五分位数Pearson的Fisher平均。两种置换为所有患者随机排列和来源内患者排列，完整分位数向量一起移动。499次Monte Carlo置换，绝对统计量双侧及+1修正，单检验alpha=.05。这是借鉴统计量的设计实验；未复刻Pelka的双尾最小尾计数定义，也未重学基因程序或网络。

```bash
python -B scripts/simulate_patient_program_readouts_v1.py \
  --output inventories/analysis/2026-10-24/program_readout_simulation_v1/artificial_results.json
python -B scripts/simulate_patient_program_readouts_v1.py \
  --repetitions 3000 --seed 2026102402 \
  --output inventories/analysis/2026-10-24/program_readout_simulation_v1/artificial_precision_results.json
```

首轮seed2026102401，每场景300次，实际UTC2026-10-23T14:02:35.149196至14:02:40.528788，exit0。零场景拒绝率Monte Carlo误差较大，另固定新seed、完整全部场景3000次提高精度，不据单项结果停止或换方法。精度轮实际UTC14:03:32.375508至14:04:28.172210，exit0；UTC+8为22:03:32至22:04:28，Melbourne为2026-10-24 01:03:32至01:04:28。两次全部120结果行均保留。

## 人工结果

以下为来源内患者置换，数值是3000个模拟数据集的拒绝比例；它们不是项目的真实阳性率，也不是FDR调整后的网络检出率。

|人工情形|每类型细胞数|均值|q75|q95|q99|五分位综合|
|---|---:|---:|---:|---:|---:|---:|
|全群体活动协同|50|89.2%|87.4%|82.0%|72.5%|88.2%|
|全群体活动协同|200|91.5%|91.1%|89.6%|84.6%|91.5%|
|少数高活跃细胞强度协同|50|7.3%|5.5%|26.7%|91.3%|35.5%|
|少数高活跃细胞强度协同|200|6.3%|4.7%|32.8%|100.0%|80.8%|

在仅来源均值移动的人工场景，未分层的均值相关检验三个细胞数条件均100%拒绝；来源内置换为5.7%、4.4%、5.3%。总体关联在该场景确实存在，因此不能统称统计假阳性；错误在于将其解释成来源内协调。

来源内独立场景的分层置换拒绝比例范围4.10%–6.17%。完整结果含逐项Wilson95%区间，部分区间未包含名义5%，**不宣布每个条件已校准通过**。许多读出共享同一模拟数据，跨格偏差相关。当前只是有限理想化设计的性能观察，真实设计仍需加入不等细胞数、稀疏计数、缺测、重复材料、连续协变量和学习过程不确定性再校准。

q99在理想化稀有强信号中表现好，不表示小细胞数的真实q99可信，也不据此把q99选为真实主终点。模拟没有dropout、重尾离群污染或完整RNA测量噪声。五分位综合对强尾部信号有稀释：它是明确取舍，不是万能替代均值。新路线须先真实覆盖和拆半/稀释诊断，后冻结关联家族。
