# 原九来源空间溯源与下一轮整合比较登记

本记录只针对原九来源免疫图谱的全局12群工作审阅，不代表其他广泛TME／scVI工作流状态。本轮结果、命名表、成员关系及图件已在私有审查包中记录；本次未运行新整合。

## 当前空间的实际计算范围

原共同模型使用来源平衡的244,668个合格landmark拟合PCA（设置3000 HVG、50维），再将全部2,670,057细胞投影到同一基底。Harmony在全量PCA坐标上以dataset为batch运行。全局12群的Leiden消费全量Harmony近邻图，k=30、resolution=0.1。

大数据分支的UMAP另用100,000个landmark在Harmony表示中拟合内部近邻图和布局，再transform其余2,570,057细胞。不能把该UMAP描述为直接消费全量Leiden近邻图。当前命名图沿已有annotation主分析资格绘制2,667,542细胞；primary不是原发灶或临床纳入资格。本轮只重绘与命名，未重拟合PCA、Harmony或UMAP。

依据为归档PCA／UMAP fitting scope、实际biology producer大数据分支及坐标／成员验收。原九来源共同模型与其他工作流的更大参考投影分开解释。

## 下一轮候选：已登记，未执行

- 未校正PCA＋普通近邻，作为控制臂。
- Harmony：同一PCA的校正表示，再建普通近邻。
- BBKNN：同一未校正PCA的来源平衡近邻图，UMAP／Leiden必须消费该图。
- scVI：从逐来源核实的计数层学习潜在表示，再建近邻。

先冻结输入资格、共享可测的稳定特征、训练／评价池、batch层级和资源；scVI计数层须与归一化表达、PCA及未经审阅的分数型残差区分。结构缺测不补作生物零。原历史基线的全量／landmark范围保持记录；新的受控比较统一冻结拟合与评价范围，避免把范围改变归因于算法。

BBKNN需记录每批近邻数、有效批次数、trim及实际度数；每批3个、9批的初始邻居为27，不直接等同普通k=30。图参数、Leiden分辨率、UMAP拟合／投影范围和随机种子需明确。scVI并非在原PCA上再校正。

来源混合与生物保留并重；稀有和来源特异群、混合／未决群及T身份—状态边界优先审阅。原生表达继续用于marker与程序描述；当前12群及旧270标签均非独立真值，不以二维图更均匀作为唯一优劣标准。参数仍待资格／资源预检，本文件不是已冻结的执行合同。
