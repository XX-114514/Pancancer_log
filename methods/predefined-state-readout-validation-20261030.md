# 预定义状态读出验证与候选接口

承接[状态与模块接口方案](predefined-state-programmes-and-module-interface-20261030.md)。本文件描述固定验证协议，不代表生物学状态或新模块已验收。

## 输入与角色

输入为已冻结并通过数值读回的官方pyUCell评分，以及原生细胞行、表达单位、来源角色、工作身份和患者键侧车。评分参考、软件版本与输入校验和必须保持一致。开发与description_only分别汇总；未知患者不进入患者层面的相关分析。工作聚类编号不能自动当作生物父类。

## 读出诊断

以来源、材料单位和工作亚型分组，固定种子进行10次细胞随机拆半。均值与0.95分位均保留诊断；20、40、80细胞分别进行5次无放回稀释。按原组至少40、80、160细胞分层报告，不根据结果改变门槛。

来源和工作亚型内至少10位已验证患者时计算拆半Spearman。患者内的多个单位先等权汇总，以避免把同一患者多个材料当独立样本；这一步只定义诊断权重，不认证材料生物学兼容。对第一预定拆半进行200次患者bootstrap，其他拆半报告相关中位数。常量程序的相关保留缺失，不当零。报告与检测基因数的相关，不能仅凭相关判定技术伪影。

拆半与稀释只检查细胞抽样稳定性；子集与完整集重叠，不构成独立验证。尾部分位是否适合科学读出，仍需足够细胞及独立来源证据。

## 排序与基因空间敏感性

使用作者pyUCell 0.8.0 CPU average-ties路径、missing_genes=skip、无图平滑。每材料/工作亚型固定哈希选择至多2细胞，每来源至多512细胞，比较rank=1000/1500/3000和共同/原生唯一实测基因排序空间，共6种设置。

本比较固定已评分的签名基因子集，只改变排序背景和截断，避免两个因素混杂。它不等于完整原生签名恢复；别名与缺失签名基因的恢复需要独立版本。共同空间rank1500必须与先前评分一致。原生表达继续使用原采用计数层和ambient减量，并核对总RNA。

## 候选C/S/M/Q

- C：当前分析范围内单位×工作身份的计数及比例，分母不得冒称全TME。
- S：材料单位×工作身份×程序的均值候选。
- M：观测、适用性与正式模块准入分别表达；未知、不适用和低支持保持NA及原因。
- Q：细胞数、细胞抽样误差诊断及患者/材料映射；细胞抽样误差不是患者推断误差。

类型限定程序按参考适用范围处理，不凭分数高低跨谱系贴标签。精确工作身份桥接不等于最终身份接受。所有正式模块准入在来源、材料、父身份、资源与读出审查完成之前保持关闭。不能将S的缺失填零或将有符号残差截断后直接送入旧组成算法。

## 实现与检查

[读出诊断](../scripts/validate_state_readouts_v1.py)、[官方排序敏感性](../scripts/validate_state_rank_sensitivity_v1.py)、[独立产物审核](../scripts/audit_state_readout_artifacts_v1.py)。产物审核覆盖全部保存均值、q95读回、拆半误差重算、稀释缺测模式和组成总数；不冒称独立重算了所有相关系数、bootstrap或生物学结论。

原始矩阵、个体与材料轴、基因资源和完整运行日志保留在分析环境。协议本身不包含这些产物，也不授权临床筛选或新模块拟合。
