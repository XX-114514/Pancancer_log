# 预定义状态程序、发现补充与模块接口

日期：2026-10-30，Australia/Melbourne。用户要求以现有算法推进细胞状态发现并接入后续模块；本轮进一步明确以文献预定义表达程序为重要起点。本方案承接[下一阶段研究设计](CM-project-next-stage-20261030.md)，不新增估计器，不以结果显著性挑选程序，不修改历史2026年10月CM（v20261010）。

## 1 任务对象与路线调整

最终对象是患者/材料内、给定细胞身份的连续功能状态及跨谱系协调，不是给每个细胞强制再贴一个互斥标签。状态矩阵、细胞组成矩阵与测量mask分别交付。预定义程序不等于功能真值；表达富集、推断通路活性、谱投射usage、参考离散状态保持各自含义。

采用三条互补路线：

1. 固定文献资源的功能表达程序，由官方UCell/pyUCell计算细胞评分，提供解释坐标与可迁移基线。
2. 对有合适参考的谱系使用官方固定参考投射，T细胞优先TCAT/starCAT；参考缺少的谱系不能生搬其标签。
3. 使用作者cNMF或GeneNMF发现补充程序，或用作者Spectra在先验约束下调整/发现程序。识别与既有程序的重合及新增信息；当前自定义NMF保留探索对照，不独占正式状态定义。

先测量可用功能，再由训练侧可靠性、适用谱系、原生基因支持及独立投射决定模块输入。不能为固定状态数量强留程序。

## 3 预定义字典的结构

每个程序必须记录：稳定ID、名称、完整基因/符号版本、正负方向或权重、适用谱系/组织、出处及原作者、资源revision/校验和、评分算法和归一化、原基因数/实测数、可测mask、技术/身份/功能属性、与其他集合重叠、开发暴露角色及模块准入状态。

按类别组织，而不是全部混成一个state列表：

- 通用过程：I/II型IFN相关响应、周期、缺氧、应激、抗原呈递、炎症及代谢。共享过程仍需在谱系内解释，不能将原始跨类型评分差当状态差。
- 谱系功能：例如T细胞TCR/细胞毒/调节/耗竭相关；髓系吞噬、炎症和呈递；B/浆细胞功能；基质ECM/收缩、血管反应等。每项须有合适资源依据；不手写几个marker冒充完整文献签名，不将髓系简单压成M1/M2。
- 技术/处理过程：热休克、解离、线粒体/核糖体背景单列诊断。可真实存在，不自动称体内功能，也不因影响研究目标而静默删除。
- 身份参考：用于注释对照、混合调整和循环性审计，不自动混入功能状态模块。

基因重命名与一对多别名先核HGNC/原注释；不做模糊字符串匹配。字典中的同义/高度重叠签名先报告冗余，训练侧选择一个代表或保留明确层级；避免同一批共享基因制造跨程序协调。保留原资源命名，细胞周期等名称与基因内容不一致时单列审阅。

## 4 当前可执行试点

复用已接受开发集轴及采用层计数，在同一冻结共同唯一实测基因空间调用官方pyUCell 0.8.0。wheel单独展开到新run vendor目录；不升级活跃环境。先256细胞真实smoke与手算/分块不变性检查，成功才继续完整现有开发范围。表达、患者、单位轴和状态数组不离开数据服务器。

资源固定Spectra commit `9c079a584ab71ea83e1e0ed471f678d2f2a997a2` 的默认JSON。该文件当前含181过程集合，150全局、31类型限定；它不是50身份集合的替代或完整TME专用功能库。当前T/NK只选择global/CD4_T/CD8_T/Treg相关条目；类型限定条目在精确身份门控接受前一律诊断。

第一版测量门槛：在冻结基因空间内至少5基因且覆盖原列表70%；此为事前项目试点门槛，不声称文献验证了它。未过门槛保存原因并不评分，不将缺失基因补零。本次共同基因空间只是可比较基线，不能当全转录组；下一比较来源内完整实测基因空间并审计别名。max_rank=1500、average ties、无kNN平滑；后续按检测深度预先比较1000/1500/3000，不以下游CM显著性选值。

输出细胞×程序侧车、源级检查点、单位×工作亚型均值/中位数/0.9/0.95分位、完整程序覆盖和module_input_contract。分位数只作诊断，尚未证明尾部可用。患者键与生物材料/技术重复分别保存，不把同患者的多个材料简单合并为一独立样本。

## 5 历史资产复用与版本边界

项目2026-10-14/15已有全谱系cNMF/Spectra候选与官方UCell，4,532,933细胞/814程序的完整原生投射及抽样手算审核记录。算法接受不等于正式状态。先登记旧字典、身份、来源、患者与当前版本crosswalk；无共同轴的部分不直接合并。新试点的增量是当前输入上的固定文献程序测量，不重复把旧候选生成包装成新发现。

髓系、B/浆细胞、血管/基质以及恶性细胞的准备同时登记。先对稳定父类做预定义测量，再按合格来源/患者推进发现；无须等所有稀有细身份完成。恶性表达程序需单独考虑谱系、组织来源与CNV证据。旧T/NK试点不能代表全TME状态发现已经完成。

## 6 接入模块发现的阶段门槛

| 阶段 | 产物 | 进入下一步的条件 |
|---|---|---|
| P0 资源与输入 | 预定义catalog、患者/材料角色、父身份和测量mask | 来源、别名、适用谱系和开发/验证角色可追溯 |
| P1 状态测量 | 细胞分数、单位/患者读出、拆半/稀释、检测深度敏感性 | 来源内同父群可靠，不靠技术深度或身份混合解释全部变化 |
| P2 程序整合 | 预定义、TCAT及cNMF/GeneNMF/Spectra的crosswalk | 明确共识/新增/来源限定/技术，训练侧固定代表集合 |
| P3 模块输入 | C组成、S状态、M观测mask、Q误差/质量、患者与材料映射 | 独立患者数真实，未知与不适用NA，参考/缩放只学于训练 |
| P4 现有模块基线 | 组成基线、Pelka式分布协调、DIALOGUE或多细胞MOFA | 共同患者/可测域、来源内支持及来源/患者外评价；不只比训练重构 |
| P5 科学验证 | 独立队列恢复、组成/亚型调整前后、空间/临床补充 | 验证集不回流定义状态；共变不写成通讯因果 |

不要把S的有符号残差直接塞进会NA填0/负值截断的旧CoVarNet入口。不同视图的尺度、缺测mask和学习目标先按作者工具接口核定。状态只进入固定训练侧的模块发现；临床或空间评价不能反向筛选字典、rank或程序数量。

当前优先交付P0/P1及P2对应，不开始新的临床关联或高维模块拟合。若简单现有模型已回答问题，优先完成生物学解释与独立复现，复杂自建模型不作为默认目标。
