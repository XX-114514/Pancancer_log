# 方法文档

`methods/` 只保存当前认可、仍应执行的方法逻辑。历史方案、被放弃方案及选择理由进入 `decisions/`；某次运行的具体参数进入 `runs/`。

每个方法文件建议包含：

- 目的和适用范围；
- 输入与前置验证；
- 处理步骤；
- 参数与默认值来源；
- 输出；
- 验证；
- 已知限制；
- 相关代码与 run；
- 版本和变更依据。
