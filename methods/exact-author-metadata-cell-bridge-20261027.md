# 从历史聚合键恢复作者样本

整合对象中的`orig.ident`或旧聚合组不自动等于实际组织样本。原生cell ID、旧表达单位、作者样本、GSM、病例和物理文库分别保留；恢复对应时不修改原档案行轴、表达、身份或既往模块。

先检查可用原始H5AD的obs、作者公开细胞表和原GEO附件名。历史ID可能含分片包装、来源、旧聚合组和完整作者细胞键。只有明确记录的编码关系可以复现；本实现支持历史`source|project_v3_sample_id=...|cell=...`结构及明确的冒号转下划线规则。保留作者样本前缀、大小写、完整barcode和全部后缀，不以末尾barcode匹配。

构造作者键之前检查重复与编码碰撞。重复作者键即使附属元数据相同也不静默合并；一对多、未匹配和无效命名空间分别记录。多个档案行对应同一作者行时报告重复，不自动删细胞。空档案不能通过完整对应验收。

作者细胞到样本、病例、材料、解离方法及作者标签的映射通过后，以独立侧表连接原始行轴。旧聚合单位保持原样，另外生成实际作者样本登记及旧单位到新单位的多对多关系。未进入当前档案的作者细胞不自动补回。病例键仅在来源内使用，作者样本数不当成独立患者数。

独立审核不用生产匹配函数：直接重建编码并以一对一关系连接全部档案行，同时对照原始H5AD观测字段、原GEO处理文件名和材料描述。作者病例标签与GEO病例标签属于不同命名空间；同一GSM处理文件建立样本桥后，应检查全部病例关系是否双向唯一，而不是要求标签中的数字表面相同。数字差异原样保留并登记别名；病例关系不唯一时仍为冲突，不能通过改名消除。每次失败保留原审计、修订依据和新版本。该对应不自动证明跨研究患者独立性或临床终点资格。

原论文的临床组织制备与离体实验分开审阅；流式活性测量不自动解释为谱系分选。GEO与原论文的试剂版本冲突保留，不将二者均为单细胞的事实扩大为版本一致。原作者标签是来源证据，不是新共同身份或独立真值。对应完成也不自动通过QC、技术重复或最终分析视图。

新来源资格工作表可以将一个旧聚合单位拆为多个作者组织样本。保持原存储单位数量和档案细胞总量；新表明确区分原生单位、已恢复作者样本、物理文库及患者。原生父单位包含肿瘤和正常时，必须通过逐细胞覆盖层选择子样本，不能将整个父单位加入肿瘤白名单。服务器与客户端独立构建工作表时，按稳定单位键、来源、资格、细胞分母及父单位关系计算同一语义SHA，并核验全部覆盖行。

优先复用原始H5AD obs或已保存的作者元数据导出。较大RDS不能仅因文件存在就当作已检查全部meta.data；已转换H5AD的患者和组织字段仍要追溯转换代码，核清哪些是作者原字段、哪些为后续推断。
