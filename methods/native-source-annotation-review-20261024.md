# 来源内原生表达与参考注释审阅

承接[完整分层方案](full-context-atlas-hierarchical-annotation-plan-20261023.md)和[发现试验](full-context-annotation-discovery-pilot-20261023.md)。当前执行见[run](../runs/20261023_full_context_hierarchical_annotation_v1.md)。本阶段产生可追溯的局部注释建议；统一身份、生产模型及全量标签资格另行验收。

## 问题与冻结范围

判断相同细胞在A（来源内分群）、B（联合分群）、C（既有粗谱系内分群）中形成的候选群，在原生表达上分别支持什么身份。采用发现阶段预先声明的第一个种子，不依据身份、CM或临床结果挑种子。保留全部已冻结来源、选择器、旧标签、三个候选分区及未分群细胞。试验按来源/旧标签等分层抽样，其比例不解释为完整来源的组成。

当前A/B/C粒度不同，标签支持率不能直接用来选赢家。后续同粒度比较、谱系特征敏感性、稀有/未知群及全量映射依原完整方案推进。

## 原生表达与参考预测

1. 按来源读取原生稀疏计数，完整RNA总量作CP10K分母，保留明确测量mask和唯一物理基因映射。未测量及符号歧义不填生物学零；零RNA不作预测。
2. 冻结服务器现有CellTypist模型文件SHA。Immune All Low提供较细免疫类型，High提供较粗类型；器官参考使用现有肺或成年乳腺模型。模型描述与类别轴保存私有。
3. 免疫参考适用范围为原生免疫多marker支持或既有免疫粗路由的细胞；这个入口本身不是已接受新身份。器官参考用于表达相似性审阅，不能单靠正常组织参考判定癌细胞良恶性。
4. 至少80%的模型特征在该来源可测且唯一解析才预测。完整原生归一化后按测得特征匹配，不对模型子集重新归一化。遵循现有官方缩放、上限裁剪及一对其余类别概率；0、1、多个类别超过0.5分别保留为无匹配、唯一建议、多匹配。概率不是校准后的身份正确率。
5. 四个缓存模型的无副作用预测均与官方API进行实际数值对照。模型对象前后指纹必须一致。参考训练与本次来源的潜在重叠尚未排除，预测一致性不能当独立准确率。

参考：[CellTypist官方模型目录](https://www.celltypist.org/models)、[多标签预测说明](https://celltypist.readthedocs.io/en/stable/notebook/celltypist_tutorial_ml.html)。

## 局部身份、状态及边界

来源×候选群至少30个RNA可评估细胞才提出群级身份。每个细胞需检测到至少两个面板基因；B细胞另要求CD79A或MS4A1锚点，避免仅靠CD37/CD74。群内至少20%细胞支持的谱系参与审阅；多个不相容谱系并存时留未决。T细胞的细胞毒NK相关表达不另作独立NK谱系；浆细胞包含的B相关表达同样分层处理。这些是预定审阅规则，不是普适诊断阈值。

细身份同时要求原生证据和过半群细胞获得一致的唯一参考建议；缺少支持则保留粗身份。Treg需FOXP3与IL2RA/CTLA4共同检测，CD8 T需CD8A/CD8B及CD3共同检测。γδ T要求TRDC、TRGC1/2及CD3D共同检测并有多数参考支持，名称保留RNA候选/正交证据待核。群内少量γδ候选不会把整个群改名为γδ T；候选占比另列。髓系分型采用各自原生面板及参考支持。

细胞毒、IFN、增殖、调节、初始/记忆和功能障碍相关RNA面板另列，不从面板分数直接宣称功能。恶性证据独立保存，不把上皮等同恶性，也不把免疫谱系当良性证据。

## Marker、展示名及版本对应

本轮计算本群原生平均表达与检测比例，优先与同来源、同候选方法、同原生支持大类的其他群比较；不存在可比较同大类群时，明确标为同来源其他大类参照。按表达比及检测差异排序，排除主要线粒体/核糖体和免疫球蛋白家族展示基因。输出一个展示marker，其余候选保留证据。

当前证据类型为`own_group_expression_specificity_not_inferential_DEG`，来源为`own_source_pilot_group`。没有产生生物重复层面的DEG检验或P值；后续有本群有效DEG时依原命名约定优先使用。不得将本轮排序称为显著DEG。

展示名采用`celltype_MARKER_number`。数字是来源/方法内部的候选群序号，独立列保存来源内ID和完整SHA；当前不是文章统一编号，也不代表每个数字都对应一个不同生物类型。每个群保留旧大类/细类及作者证据对应，不覆盖旧标签。

## 输出与验收

- 原生计数、完整预测分数和概率矩阵仅RAM使用；私有磁盘保存小型预测类别/匹配数/最高概率及群级证据，容量上限固定。
- 全来源检查候选群轴、RNA分母、旧新对应、参考代码/无匹配/多匹配/范围外分母及SHA。
- 按冻结试验细胞数选择最小来源，独立从CSR指针读取全部该来源试验细胞，调用官方API复算参考预测及原生多marker/选出展示候选的表达统计。
- 代表来源数值复算不扩写为全来源数值重放；计算正确与身份生物学接受分开。完整基因排名、状态均值如未独立重放须明列。
- 后续优先审阅混合谱系、小群、参考无匹配/多匹配、粗身份不一致及γδ边界，再进入等粒度和谱系特征比较。

## 两组marker锚点的限定敏感性

原规则的多谱系冲突审阅后，新增一次有版本的限定诊断；这是发现后的规则敏感性，不称预先独立验证。固定四种情形：原规则、红系锚点、中性粒细胞锚点、两者共同。其余面板、20%群支持阈值、参考预测及分群保持；完整原群判定先数值重现。

- 红系仍须满足原多基因规则，并额外检测到AHSP/GYPA/GYPB/ALAS2/SLC4A1中的至少一个。
- 中性粒细胞仍须满足原规则，并额外检测到CSF3R或FCGR3B。
- 单列未测/歧义锚点；未达到锚点要求表示证据未满足，不能证明该类细胞不存在。
- 比较每来源/方法的支持变化和未决迁移；未决减少不是正确率提高。不给细胞删除、污染诊断或正式新标签。

理由来自原始研究：[SoupX](https://pmc.ncbi.nlm.nih.gov/articles/PMC7763177/)展示血红蛋白环境RNA造成非红系读数；[上皮细胞研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4924696/)显示S100A8/A9可在上皮肿瘤细胞表达。这些文献支撑核查必要性，不能替代本项目的污染或身份判断。当前不重新处理所有来源或修改原生计数层。3项实际反例核 globin-only、S100-pair-only及未测锚点；新结果只作为来源内谱系复核入口。
