# CM来源解释：排除分组基因的留来源参考诊断

## 范围与参考资格

承接2026-10-14免疫图谱CM（v1，T_whole_TME_primary_tumor）的固定功能代理。原2026年10月CM（v20261010）9模块、正式身份/状态及既有临床/空间有限家族保持。当前问：能否在原分组基因之外恢复粗谱系及操作性RNA捕获类别，作为后续细胞来源解释的资格。

先按清单SHA核实际现有三视图输入的来源/视图、完整18大类缓存的原生行命名空间/基因和来源范围。旧缓存不是当前范围全类别的自动替代。当前原免疫图谱中固定原CM材料成员，完整保留边界/未定及原T中共捕获/均未捕获、未捕获核心和缺少严格锚点等情况。类别是RNA测量定义，不是生产性受体/功能金标准；没有使用临床结局选择细胞或调定义。

## 事前固定实验

粗口径四类：原T、原NK、其他已赋大类、边界/未定。细口径在原T中保留7种RNA捕获定义；严格锚点只作原定义支持，不将未检出解释成无该细胞身份。T/NK边界保留在粗口径不混入原T细口径。两原整数阈值均有完整资格计数；真实模型使用事前固定主阈值，不按效果换阈值。

每源/任务/类在原材料文库间按固定hash轮流抽取，最多每文库60、每源类600；各任务选择并集一次读取原RNA。全部源共同可测、物理唯一且无歧义的基因，去掉全部34原分组基因及对应物理别名。完整真实表达、细胞选择、特征/载荷、模型权重、预测和重采样数组仅RAM。

两任务×四个完整留出来源共8位置。每训练类别至少20细胞、3材料文库、2来源，必需QC及PC可变；失败不删类别/协变量。每折只在训练细胞中拟合类/来源/材料平衡权重、至少1%加权捕获/正加权方差的前2000基因和20个加权PCA；列序打破并列。完整原生RNA分母，训练尺度原样用于留出来源。

比较固定L2多项logistic（C1、lbfgs、2000次、tol1e-8）：只有RNA深度/检出QC；20RNA-PC加同样QC。所有类别保留，不搜索参数；显式softmax、完整加权损失/梯度与L2、所有概率及独立混淆计数复核。合成可分三类、常量QC与不可估计RNA先验证。

每类训练/留出细胞和材料覆盖完整报告。所有留出类别都至少20细胞/2文库才报告完整宏F1/平衡准确率，覆盖不足保留缺测；整体选定细胞损失附适用范围。主描述为类/材料平衡的成对logloss改善，2000材料块bootstrap仅针对固定留出预测；缺任一类别的重采样保留失败，至少1800完整draw才给pointwise区间。文库不是已审独立患者，区间不含重训练方差，没有新P/FDR或临床预测主张。来源差异按情景解释，不强求跨癌种一致作为唯一价值标准。
