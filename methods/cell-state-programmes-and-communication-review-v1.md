# 细胞身份与状态程序分离：研究方案 v1

## 当前问题

目前major/subcluster主要是身份、亚型及描述性marker。状态可能在一个子群内连续变化，也可被多个亚型同时表达。研究目标是识别可复现的表达程序，再问组成生态与通讯线索如何随状态改变；不把获得显著LR作为状态标签成立条件。

源码错误、文件传输和配额曾阻断执行，属于技术事件，不作为生物学阴性原因。不同来源/癌种的生态差异可接受；应分别说明可测性、来源内效应、跨癌种一致与真正独立验证。各行证据见正式runs和对应RESULTS，旧结果均保留。

## 方法选择

| 方法 | 本项目用途 | 局限及判定边界 |
|---|---|---|
| Spectra | 优先探索：使用已审粗身份及过程字典，分解共享和谱系内程序，允许新程序 | 先验与粗身份错误会影响结果；不是自动消除来源/环境RNA；训练结果须来源诊断和外部投影 |
| cNMF | 不依赖先验的对照；来源内/谱系内重复分解后匹配meta-programs | 需K/重复稳定性与技术程序审阅；某些因子仍是身份或批次；不能称所有NMF因子为状态 |
| UCell / AUCell | 固定模块后单细胞rank评分及分块投影 | 打分不是发现方法；抗组成变化不意味着消除深度/dropout或签名重叠；不能用major均值冒称UCell |
| cell2module | 后续大规模、多模态/计数因子路线的候选 | 本轮仅读官方方法，不已安装/运行；先做小规模成本与稳定性比较再决定 |

原始研究与官方实现：[Spectra论文](https://www.nature.com/articles/s41587-023-01940-3)、[Spectra](https://github.com/dpeerlab/spectra)、[cNMF](https://github.com/dylkot/cNMF)、[UCell](https://github.com/carmonalab/UCell)、[cell2module](https://github.com/vitkl/cell2module)。Spectra论文的免疫治疗结果属于其数据，不自动成为本项目验证；固定官方default JSON实际181非空程序，不能与论文231集数目混用。

## 状态层的内容和标签

保留majorCluster、subCluster、原数字编号与identity_version。新增独立sidecar，以稳定cell_id关联：program_id、连续score、score_method、model/reference_version、gene_coverage、state_candidate_labels（可多值）、confidence、review_status、technical_flags。低覆盖记unscorable；未审核记pending；测到低分不是不存在状态。

- 通用：细胞周期S/G2M、IFN响应、TNF/NFkB、缺氧、UPR/ER应激、热休克/解离相关应激、凋亡相关程序。
- T/TNK：细胞毒、TCR/活化、肿瘤反应样、耗竭相关、增殖与IFN分别记录；没有可靠CD4/CD8身份时不据签名晋升身份，TCF7/PDCD1单基因不能证明progenitor/terminal exhaustion。
- 髓系：IFN/抗原呈递、炎症、吞噬/脂质代谢、ECM/血管生成与应激；不强迫M1/M2二分。
- B、内皮、成纤维和已确认恶性上皮后续使用适用谱系程序；EMT/侵袭或肌成纤维分化与身份关系单独审阅。

示例仅说明格式：`T_cell_CCL5_38`保持不变，另存`cytotoxicity_high; IFN_response_high`。一个细胞可以同时多个程序活跃；默认发布连续分数。高/低阈值需校准/稳定性，不能按每库固定上四分位强造相同状态比例，也不以最高分强制单标签。γ减α基因集合不证明IFNγ刺激特异性。

## 下一阶段顺序（未执行训练）

1. **有界准备诊断**：全部既有11源/52来源-major组合/2028单位，固定181集，核符号匹配、检测、重叠、全局LR剔除损失及复杂度相关。不是细胞状态发现或患者推断。
2. **单细胞试点**：在已审T及髓系范围按来源/患者/文库均衡抽样，RNA原生counts与身份对应全审；不直接对全4.7M做密集矩阵，也不将新3.18M未注释合集混入训练。依据覆盖冻结确切来源/单位/排除/样本量和留出来源，再安装隔离版本的正式实现。
3. **发现与对照**：Spectra共享+谱系特异；cNMF K候选/重复/随机种子事前固定，以重构、稳定性和来源诊断选模型，不按通讯p或疗效选K。技术标志程序保留并标注，不自动全部回归删除。
4. **固定与投影**：模块基因、权重、命名冻结后，用来源留出/独立队列投影和UCell类rank评分复核；病例重复和发现使用史分别检查。验证数据不重学或重新挑最优marker。
5. **链接9CM/细胞对**：先将每样本的major内程序均值/分布与原CM活动、组分联系；身份组成与状态变化分开。另建state-programme协同网络，使用SP编号而不复用CM01–09。然后在固定状态内/不同状态之间检验可测LR和接收程序。
6. **总体与条件效应并列**：保留基础生态模型、加入身份混合、发送共同状态、接收自身表达及接收状态的分步模型。按实际生物问题区分混杂/中介/结果，不把所有状态一次调整掉；做LR/读出基因重叠诊断和完整受体同细胞核查。

验收需要：程序多基因共同表达；原编号内部可观察而不完全由亚型比例解释；重复分解和来源投影稳定；复杂度/应激/批次敏感性明确；所有稀疏/阴性/模型敏感情况保留。状态重复可成立而LR特异机制仍不成立；不得把统计或数值PASS写成耐药、抑制或因果驱动。

## 2026-10-13 实际准备诊断带来的方法修订

[完整9412记录结果](../inventories/analysis/2026-10-13/state_programme_readiness_v1/RESULTS.md)：6386与复杂度abs rho≥.5；1036在全局LR剔除后损失至少半签名。Mac_IFNG21→5、typeII IFN17→2、T肿瘤反应样8→1。状态发现保留完整过程基因；通讯关联针对被检接口/共享读出做控制，全局LR剔除作为明确敏感性，不按最有利p决定版本。默认mean-log易受复杂度影响，优先正式factor与rank评分对照及RNA深度匹配诊断；rank也不保证消除dropout。当前只是major缓存准备，没有拟合Spectra/cNMF或给单细胞分配状态。
