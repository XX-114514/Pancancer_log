# 外部冻结细胞池的原生计数输入

## 目的与范围

接续[谱系/测量资格](NSCLC-native-MFA-external-role-and-measurement-qualification-v1.md)，为后续固定表达程序测量准备计数。覆盖所有61来源—臂/1690文库/四冻结候选池，共6760位置；小群、零群、未知患者和所有材料类别均保留，不按表达结果换注释或选来源。本阶段不产生外部因子分数、通讯/临床检验或正式状态。

## 原始数据与物理基因

原52来源从既有权威core X的冻结合格细胞行读取，免疫图谱从原始layers/counts读取；工作稀疏块规范重复坐标与存储零，权威对象不写。完整物理来源RNA作质量分母，检查非零计数不越出该来源测量范围。

原肺癌完整31831基因轴定义共同计数宇宙，并按来源既有精确符号/稳定ID别名对应唯一可测物理列，冲突保留不可测。每个来源归档只含真正可测的共同原生基因列，附原肺癌轴列号和全局文库/池索引。没有将不可测基因填成表达阴性，也没有只取学习特征。

原始整数计数按物理文库和冻结池求和。保留完整来源RNA量、共同宇宙RNA量、检测基因数、各自逐细胞log统计、符号前缀线粒体/核糖体RNA比例及零RNA细胞数。当前父群捕获数/比例仅作诊断，不能直接宣称等价于肺癌作者原生T/NK等完整父分母。

## 资源与版本

v1在未压缩数组的保守磁盘上限检查处停止，尚未创建输出或读取新RNA。v2不改计数精度、来源/细胞/基因范围；完整整数计数先只保留RAM，所有来源归档先在RAM无损压缩，确认准确总字节加32MiB辅助空间小于256MiB后，再通过新鲜精确df/group quota门槛写入。

保留500GB十进制余量与1GiB缓冲，RAM需覆盖两倍未压缩数组及3GiB工作空间。压缩不够时明确停止，不截断来源或降精度；所有失败与旧代码保留。没有新表达下载。

## 核查与边界

所有6760池细胞数必须与已独立审阅metadata精确一致。对全部本次选中角色细胞，从原始RNA重新计算44个事先固定公开标记的logCP10K与检出计数，并与已有独立核验结果对照。该控制增加原52来源选中角色细胞的raw证据，不冒充全部其他细胞或全部基因的独立原始重放。

RNA读取前用metadata和固定哈希选择96审核池，覆盖每个来源、四角色、小群及零群。正式接受前另从原始矩阵独立核这些池的所有可测共同基因及质量统计；来源归档/轴/和数等结构对所有6760池核对。仅计算完成不能代替独立数值验收。

原归一化校准需完成独立复算，RNA质量与平台可比性和新外部推断合同也须单独固定。原生计数输入准备可与归一化数值诊断并行，不表示后者已通过。患者重复取样、材料/时点与同癌种/跨癌种证据仍按既定合同处理；不能将未知样本替代单位变成独立患者。

患者行、完整计数、学习列表和科学效果只服务器/获准对话，公共仓库只方法、代码、执行轨迹及SHA。原172身份、2026年10月CM（v20261010）及原生肺癌10因子不改。
