# 原生历史 CNV 与恶性证据登记

## 保留两条独立信息轴

细胞身份与恶性证据分开。表达呈现上皮、免疫或其他谱系，均不能直接确定恶性。原生档案中已有的 CNV、作者/历史判定、方法状态和版本继续保留，不先重新计算所有来源，也不将字段存在当成已完成评估。

登记程序逐来源核对行/身份轴，保存原字段的类别计数、数值覆盖及明确的可评估/阳性组合。原始字段、方法输入和版本继续在源中；当前登记不产生新的恶性标签。

## 可评估状态与结果

| 条件 | 记录含义 |
|---|---|
| 可评估且阳性 | 原方法的可评估阳性标记 |
| 可评估且阴性 | 原方法的可评估阴性标记，不证明良性 |
| 可评估、结果缺失 | 已有评估标记，但结果未知 |
| 明确不可评估 | 不当成阴性，继续查原因字段 |
| 可评估状态未知 | 结果暂不解释；单独记录已有阳性标记 |
| 不可评估却阳性 | 保留字段冲突，待版本/方法审查 |
| 编码无法识别 | 不自动转 False 或抛弃记录 |

数值 CNV 分数存在或为零，也不能替代明确的可评估状态。三项反例覆盖无评估的 False、可评估的阳性/阴性/缺失，以及矛盾/未知编码；全量类别计数另用标记组合频数核对。

## 已定位的 V7 历史规则

已读取历史冻结报告 `V7_REFERENCE_AND_ANNOTATION_LOGIC_CN.md` 第9节。其“样本内 CNV cluster 主判定”与“单细胞双方法交集/并集证据”是并行定义。

历史 cluster 主规则要求至少30个细胞，并以 inferCNV 阳性比例及相对样本参考阈值的平均负荷，或可评估 Copykat 的非整倍体比例支持。历史单细胞严格交集、敏感并集及互斥 tier 则按另一套证据轴构建。因此严格交集阳性不必完全包含于 cluster 主恶性集合，不能把 tier 类别简单相加替代主判定。

这段说明用于解释原字段，不是本次重新选择阈值或重跑 CNV。当前所选来源与历史全量范围不同，不能用旧报告总数要求当前子集逐项相等。后续标签 crosswalk 保留主判定、严格/敏感集合和证据版本，分别报告方法作用域；`not_candidate`、`not_evaluable` 与“未检出恶性 CNV”保持区分。

## 下一验收

在调用历史结果前继续核原方法适用谱系、参考细胞、基因顺序、输入来源及版本连接。新增来源的其他 CNV 分数/条件字段先登记语义，不借用 V7 阈值直接套用。未评估或证据未闭合的记录保持明确未知，不能用新的表达注释代替基因组证据。
