# 全原生关联家族的结果解释

## 入口与科学边界

接续[固定关联合同](NSCLC-continuous-prior-native-association-v1.md)和[外部机会](NSCLC-native-interface-external-opportunities-v1.md)。原4800计划位置、1338效果前合格检验、10因子和12有向细胞池组合均不变。全数值审核的真实进程和启动收据绑定，证明通过且匹配生产终态/源码/全部文件后才读取效果。等待超时不当生产停止，也不重启原作业。

本阶段是已计算结果的完整解释，不新增统计模型、P、候选阈值、因子或端点。新原生MFA因子编号与2026年10月CM（v20261010）不同。原内部作者病例不能称未见外部独立患者，发送池配体与接收池程序的RNA关联不能称受体特异效应、直接通讯、主导轴或临床意义。

## 逐项交付

- 全部1338项保留原效果、P/BH/BY/MC上界、区间、原候选标记和敏感性状态。明确逐项失败于哪条原候选规则；可同时失败多项，失败计数不能相加当总分母。
- 完整接收分数、加发送自身程序、加两端免疫池比例、加完整作者亚型组成，均只是已有的同病例敏感性：报告连续有符号/绝对效应变化与同向性，不新增衰减阈值或敏感性P，不从不可识别结果自动删控制或救回候选。
- 按字面发送池—配体—接收池分组全部记录，明确同一组可能跨方向/多个因子。分组只避免把依赖的程序记录误称多条独立互作，没有新聚合P或机制晋级。参考受体集合仍按原合同保留，不能由此指定某条受体。
- 全部120因子/方向位置汇总计划数、合格数、正负方向、原校正/区间及候选数。它们是相关检验记录的计数，不是模块效应或独立轴数；零合格不代表生物学阴性。
- 每记录连接已经独立通过的外部机会清单，仅按不同GSE去重报告覆盖数量。不同分析臂或阶段不是多个来源复现，覆盖不等于同细胞受体、分数校准、模型或研究独立。
- 图包括全120位置计数、全部主要/已有敏感性效应散点，以及按冻结test_index次序分页展示全部原候选的森林图；不只画最强者。无候选时保留完整表和总览，不以图推动新阈值。

## 接受与后续

独立审核完整表的原列、所有规则/敏感性派生、字面分组、120汇总、不同GSE计数以及每图精确记录映射和SHA。数值派生及图范围通过不等于实际像素审阅，最终另查看完整代表图及相关候选页，不宣称未看过的图已视觉通过。全部科学载荷和图留server/授权对话；公共Git仅方法、代码和脱敏过程。

主结果审核后再依全家族证据规划跨来源分子测量；不重开旧临床/MMR/DIALOGUE/LR家族。若主要无原候选，不能把名义P、反向、较弱敏感性或更宽池偷换为成功，转向已有程序共同变化的队列或空间问题。资源为32MiB派生输出、1MiB审核，各核准确文件系统500GB十进制加1GiB缓冲；无新RNA下载或标签改写。
