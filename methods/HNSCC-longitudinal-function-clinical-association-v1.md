# 头颈癌功能变化与连续病理退缩的共同临床关联

## 研究问题与范围

接续[完整纵向功能](HNSCC-native-multicell-longitudinal-functions-v1.md)。上一轮已全量验收新功能测量、配对变化及同患者跨池相关。本轮问：患者间的功能变化差异是否联系连续病理退缩，两个细胞端是否都具有共同临床关联。它与“所有患者平均都朝同方向变化”、双方独有增量及直接LR机制是不同问题。
