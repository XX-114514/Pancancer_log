# 固定接口的全部既有基因轴与候选来源分流

原NSCLC固定接口不换亚基、受体或符号以适应新来源。新公开随访逐病例表的传输仍待明确许可，不通过其它入口处理该表。本阶段只读服务器已缓存基因metadata与已接受的文库/原节点捕获统计，不读取表达、临床结局或新的资料。

## 完整固定范围

- 当前机会登记的全部61个来源臂、1690文库；原NSCLC校准轴另列，不计外部验证。
- 原21条输入合同，严格使用各自declared var/count key、角色与来源掩码。9条共用合并对象的记录必须应用measured_in_source；单源feature_measured_in_source也保留。不能把合并对象的全局列当每个来源都测得。
- 共用一个原始物理文件/基因轴的8个ICB来源单独核其继承关系，原隔离角色不解除。

三指定角色的基因符号/公开稳定ID在私有事前合同中固定。仅精确源符号、稳定ID去版本及已有明确稳定ID别名；不做模糊别名、删组分、缺测补零。拒绝ambiguous_source_feature、AMBIGUOUS标签、角色多列和跨角色碰撞。元数据中的唯一物理位置仅表示测量资格上界，不证明来源正表达或复合物组装。

全部61派生轴与21原始轴分别报告，重叠来源逐角色比较；不一致则登记待审，不能自动选择较有利版本。每轴采用逐行token集合与独立列向量匹配两种实现完整核对；二者共享元数据I/O，不当独立原始RNA实验验证。原NSCLC校准仅作锚点。

## 捕获和病例机会

使用全部既有文库和节点计数，按固定大类精确字典统计T父类与宽髓系父类。未明T/NK边界不硬并T，未知大类不自动归谱系；大类捕获只是上界，不等于原细分发送/接收端已被确认。

按来源臂×来源×癌种×材料×阶段×捕获背景×ex-vivo分层，保留全部情境。两父类各>=20必须在同一文库/材料，不靠合并不同样本达标；已审患者块去重计数，未审文库另报。逐节点求和另以Counter核全部1690文库，所有分层分母守恒。多个文库/来源臂或阶段共享患者不当独立验证，原来源/临床角色保持。

当前不接受临床终点、患者晋级、细分γδ身份或新RNA评分；完整测量、明确病例/材料和未重复已关闭家族之后才能另定推断问题。来源关联、临床关联和直接分子机制分开。项目原文件只读，新任务tmpfs≤4MiB；候选定义、来源测量资格和病例覆盖统计仅服务器/获准汇总对话，公共Git仅方法、通用代码、技术维度/SHA及脱敏轨迹。
