# 共同表示候选：拟合与验收合同

承接[已接受参考输入](common-coordinate-reference-inputs-20261025.md)。固定参考行、共同实测基因及临床盲法；不以治疗结局或旧CM显著性选模型。

## 拟合范围

在固定参考并集读取原生整数计数，逐块对照既有全原生RNA总量，再计算log1p(CP10K)。表达仅驻留RAM，不保存全量表达矩阵。原生全基因档案、来源内群和证据保持权威。

全局参考重新选择共享特征，谱系参考各自选择特征；T/NK和髓系在相同参考行、PCA/Harmony参数下比较共享与谱系特征。每来源log表达离散度排名取平均用于特征选择，明确这是现有启发式，不称Seurat HVG。PCA最多50维，固定随机种子及4线程。原始PCA始终保留。

上皮、胶质、星形胶质、神经元候选保留原始PCA，供癌种、器官及克隆背景审阅；不自动强制跨肿瘤校正。其他多来源谱系拟合source-Harmony/Symphony候选。来源与癌种/模态/治疗混杂时，模型不能证明这些效应已分离。来源数不足或小参考池有明确回退记录，不静默加样或删群。

本次是全部来源参与的传导式发现。先前来源留出结果的训练/查询范围另列，不把本次参考当独立验证。

## 计算验收与科学选择分开

独立计算审计检查每个参考行/来源/表达单位/谱系曝光、原生状态与测量覆盖；模型保存哈希、基因轴、有限数值、PCA载荷正交性及坐标轴。逐模型固定有限原生查询批次，检验直接PCA投影、查询顺序一致性与冻结参考不被映射修改。该有限查询不充当全档案转移合格证据。随机PCA的fit_transform不假定与后续transform逐值相等。

科学选择另检查同细胞的类型内RNA邻域、局部群/稀有群保留、未知拒绝和来源内敏感性；来源校正混合度不单独决定胜出。用于候选身份的标签和marker不充当独立真值，作者细群与原生读出分别说明证据范围。没有合格比较证据时保持候选状态。
