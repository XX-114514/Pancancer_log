# 状态与情境细胞模块：CoVarNet改进设计审阅

版本2026-10-24；状态为算法建议与源码审阅，尚未实现新估计器或运行真实比较。目标是发现可解释状态组合在癌种、治疗阶段和组织中的适用范围。原CM与已关闭检验保留，新的方法、参数和数据划分另设版本。

## 1. 先区分两个分解层

当前组成模块的本地代码使用`NMF::nmf(method='nsNMF')`，模型为F≈WSH。它不是Kotliar的表达cNMF。后者对细胞×基因的表达矩阵多次分解、对齐并汇总表达程序，再固定字典求细胞usage；增加共识拟合改善随机优化稳定性，不自动消除来源、组成或取材偏差。[cNMF原研究](https://elifesciences.org/articles/43803)

本项目可保留第一层表达程序学习，改进第二层患者/材料×类型/状态的模块发现。第一层某程序在多类细胞表达，不等于这些细胞的患者级活动协调；第二层组成共变也不等于第一层功能协同。

## 3. 模块对象需要增加的信息

新模块拟输出：父身份、连续状态或程序、成员权重/方向、观测覆盖、患者级活动与不确定性、癌种/组织/阶段范围、共享与特有部分、外部投影资格，以及组织/临床/功能各自证据。

细胞可以同时有记忆、活化或干扰素活动；程序不必是互斥cluster。相同名字不同编号不直接合并；先用已验收身份crosswalk和表达证据确定共同父类。状态轴来自外部固定字典或训练部分学习；完整投射后再核可测性。父子比例不能当相互独立的重复特征，状态比例与状态强度也分别建模。

不能预设新模块必然复现CM02，也不将CTLA4或GZMB单marker当调节/效应细胞的充分定义。同一谱系中的状态组合可成立，应称多状态关系，不能强制包装成跨谱系模块。

## 4. 优先的六项改进

### A. 观测过程与测量误差

保留每个材料、父群的捕获方式、总细胞数、计数/基因测量掩码和程序精度。父群未捕获的状态读出是缺失；父群充分捕获、固定状态未观察到时，可在相应二项/多项抽样模型中保留0。RNA检测不支持某状态，还可能涉及深度与定义误差，不能一概判生物不存在。

全细胞程序分布先做拆半、稀释与技术背景诊断；均值、分位数、固定阈值比例有不同误差和含义。联合多个分位数时估计它们的协方差，不将同一分布的五个统计量当五个独立证据。精度权重需要上限与模型误差下限；大捕获量不能让单个患者代替更多独立患者。

采用带mask损失并不能修复未知选择偏差。分选不明或缺失依赖疾病的场景要敏感性分析；训练中全无某视图、来源间无共享状态的断裂观测图无法凭空对齐，应该拒绝估计。完整模块和可测骨架分开交付。

### B. 组成统计与身份层级

组成分支比较：原CoVarNet频率、训练内固定参考的log-ratio/ILR、以及保留分母的multinomial/logistic-normal因子模型。低计数0不靠任意伪计数解释；概率模型须校验过度离散，可用随机效应或Dirichlet-multinomial类机制。

比例闭合不仅能产生负相关：两个绝对数量不变的群，可因共同分母中第三群改变而一起升降。原分析用major内比例也有该问题。组成模型只能学习相对变化及其不确定性，不能在没有独立绝对密度/计数时恢复真实绝对丰度。

[scCODA](https://www.nature.com/articles/s41467-021-27150-6)与[tascCODA](https://www.frontiersin.org/journals/genetics/articles/10.3389/fgene.2021.766405/full)提供组成计数与树层级建模参照，属于差异丰度方法，不能直接称现成无监督CM算法。借鉴其采样/层级思想需另验证潜因子扩展。若用注释概率，不能把分数计数当无误差整数多项观测；需要潜在归类或重复抽取标签传播误差。

### C. 共享与情境特有结构

不要把“跨癌种共同”与“必须完全一样”混同。用部分汇聚：共享骨架保留，癌种/阶段中允许稀疏偏移；小组偏移向共享骨架收缩，不能为每个癌种拟合一个完全自由高维W。

同时输出三种量：情境间平均差异、情境内患者共同变化、阶段/情境中的载荷或边重塑。只有前后配对或足够交叉设计才能可靠研究某些交互；独立pre/post截面差异不自动称治疗导致变化。

“一个情境显著、另一个不显著”不等于两情境效应不同；边重塑要直接估计相关/条件关系的差值及区间。某因子在一个癌种更高只是均值变化，不自动证明细胞组合方式改变。若同时允许情境载荷和潜变量协方差任意变化，二者通常难以唯一分离；需限制潜变量尺度/协方差、偏移自由度与对齐规则，并以共同的预测协方差及重采样结果解释。稀疏惩罚本身不保证可辨识。

来源指标不应把癌种/阶段信息全部回归掉。来源与癌种完全重合时，单独技术来源效应与癌种效应不可辨识；合并成可观察情境描述，另找同癌种多来源证据。等来源加权改变目标人群，需和按患者加权结果并报，不能称消除混杂。

### D. 组成和功能的联合多视图

建议用同一材料/患者的组成与可靠状态读出两个视图，另保留视图特有因子。这样允许数量变化与状态变化共享，也允许其中一层独立变化；不能强迫所有视图共有同一组因子。

概念模型（不是已实现算法）：

```
每个父群的子群计数 ~ Multinomial(该父群捕获总数, softmax(相对丰度线性项))
可靠状态汇总 = 状态背景 + 状态载荷 × 患者潜在活动 + 测量误差
两类载荷 = 共享部分 + 癌种/阶段的收缩偏移
潜在活动 = 患者共同部分 + 材料/区域部分（有数据时）
```

组成线性项要包含适当基准/技术项，参考约束和尺度固定后才能解释。logit载荷和中心化状态载荷可以有符号；如保留非负NMF骨架，则由单独带符号图描述替代关系，不能对负值简单截断。非负因子本身并不排除因子usage之间负相关，本轮限制主要来自最终正边筛选与加性共富集解释。

形式化目标可写作观测mask下的`组成负对数似然 + 状态测量损失 + 稀疏/层级/情境偏移惩罚`。状态损失使用经验协方差或稳健噪声模型，控制视图尺度/维度，避免特征多的一层主导；正则强度在训练内选择。固定reference/和为0、载荷范数、符号与因子一一匹配减少尺度/旋转不确定性，但不能保证生物身份唯一。目标函数、优化更新和置信区间仍需推导及验证。

新模型不能用构成因子的接收读出再次证明同一因子能预测它；预测任务要留出目标状态/视图，在训练内重新学习或用其他视图投射。得到非零活动时还要核多端共同支持、后验/重采样区间和遗漏关键成员的反例。单端强信号不代表组合整体存在。

程序输入可由全部符合事前测量资格的父类×状态组成，而非手工指定几个配对。CM02是需解释的既有候选，不是真实标签，不能以是否找回它选择算法。状态字典若过大，先在发现患者内按测量/方差及冗余压缩，不用临床或CM关联P挑状态。多状态组合还要检验联合观测和跨端预测；只有两两相关，不能直接断言高阶同时组织或协同作用。

### E. 空间的进入方式

初版先用RNA发现并冻结状态组合，再在独立空间材料核测量和组织位置；这是验证而非训练先验。只有状态/样本对应足够、空间发现队列与验证队列分开时，再增加空间视图或图正则版本。

局部邻近、同区室富集和空间分离均可有意义。图平滑会人为提高邻近相似，过强时抹去免疫排斥边界；不能把用作先验的邻近再称独立空间验证。局部null保留密度、区室和空间自相关，病例是推断单位，ROI/细胞是嵌套重复。

不同患者、不同面板的数据不能仅凭共享癌种就放入同一个患者潜变量。需要可靠共同状态/锚定或冻结参考映射，无法测量的状态留缺失。解离RNA数据不能单独确定组织位置。MEFISTO提供真实连续坐标/时间的因子先验参照，pre/post两个类别不等于可可靠拟合连续轨迹。[官方说明](https://biofam.github.io/MOFA2/MEFISTO.html)

### F. 从“解释输入”改为“可迁移、可检验”

初始稳定性保留多种子，但增加患者bootstrap、来源/患者留出、跨rank匹配与外部投影误差。载荷稳定、留出状态预测和临床用途分别评价；低重构误差不是功能模块证据。

临床结局初版留在发现之外；半监督版本只能在训练内用结局，最终独立患者/来源评价，完整模型选择也要嵌套。缺患者或事件数时不靠正则化承诺泛化。是否有额外作用通过接收功能、组织和同终点增量检查；相关模块和有向机制分开，驱动需扰动证据。

## 6. 最小可行路线与公平比较

先固定同一份已验收计数、父类/状态字典、观测mask和患者划分。所有方法的特征选择、缩放、程序学习、rank/阈值选择仅用训练。若比较包含新表达学习，必须有端到端训练内重学；另报告仅冻结字典条件下的比较，两者不混称。

1. 基线A：原CoVarNet/当前冻结组成模块，说明其可测域与网络筛选。
2. 基线B：同输入、同划分的最小修正版，仅改mask/训练内尺度/单位和网络评价，区分工程收益与新模型收益。
3. 基线C：Pelka式程序分布网络和适用的多细胞MOFA/DIALOGUE；这是更换输入或架构的强基线。
4. 候选D：组成+可靠状态的共享/特有、带情境收缩模型；首先限制在可辨识的少量谱系/状态。
5. 若架构适合，再比较scITD/MANTRA；通讯任务另比较Tensor-cell2cell。scCODA/tascCODA只在差异丰度子任务中比较。

先用人工数据固定至少以下场景：无协调、仅来源平均偏移、相对组成闭合、来源不平衡、一个共享骨架加情境特有边、阶段相关改变、正负替代、稀有高活跃状态、父群缺失/富集、重复患者/区域、身份拆分合并和错误映射。另用不符合候选模型分布的场景，避免只在自己的生成假设中获胜。失败不改seed/门槛重跑直到通过。

评价指标：真实模块/边恢复、假阳性和区间覆盖、共享/特有区分、患者/来源留出预测、同细胞预算稀释稳定、缺失时拒绝估计的正确性、注释粒度敏感性及资源。不同目标和尺度的重构误差不能直接比高低；同一测试任务采用共同可测集，另报各方法额外可覆盖域。临床P更小或UMAP更分离都不是算法优越性标准。

逐项消融计数似然、mask、状态、情境收缩和空间项，确定收益来自哪里。来源置换和拟合不确定性须包括完整选择流程；学习后在同数据上简单相关得到的P不提供选择后的验证。模块跨seed/K匹配允许未匹配及拆分合并，不能用每行最大余弦制造稳定。

## 7. 推进与停止条件

第一版优先测量+mask+共享/情境结构，不同时引入深度生成模型、LR先验、连续时间和空间正则。现有独立患者量决定可估复杂度，不能以百万细胞数量为复杂模型合理性依据。

可先实现分布特征的带符号多层图，作为低复杂度原型：在可比情境内估计患者级边及误差，部分汇聚共享边与情境偏移，允许重叠成员；组合联合支持与留出预测另审。这不要求立即完成联合潜变量估计器。若进入联合模型，对情境偏移采用低秩/稀疏限制，限制有效自由度；小组仅投影并报告无法估偏移。正则化不能凭空补足交叉设计或患者数。

如果最小修正版已解决问题，则按方法改良/应用交付；如果候选在严格留出和缺失/采样场景持续优于强基线，再考虑方法论文。如果只有单癌种稳定，则形成情境模块故事；若只改善重构、不改善可靠性或迁移，不将其称创新算法成功。无论是否重设算法，现有空间固定合同和已有图谱主线可以独立推进。
