# 同输入、标准特征与原生粗路由的A/B/C试验

复用已冻结的代表性试验细胞、来源角色、原生物理行和研究重叠分组，不按临床关联重新选细胞。试验包括T/NK、髓系、上皮及其他/未决背景；富集来源作为表达比较，不能变成完整TME组成样本。原有不确定材料/患者资格保持。该试验承接[完整目标](full-context-atlas-hierarchical-annotation-plan-20261023.md)，不替代全档案交付。

首先将旧选择器核回当前原生档案的同一物理行和冻结上下文；共同候选仅保留每来源唯一实测的基因，预留RNA基因及物理别名不进入模型。标准特征选择使用原生整数counts上的Scanpy `seurat_v3`、来源batch、6500候选后取4000个非技术HVG，包含已修正的精确血红蛋白符号规则。PCA使用官方中心化ARPACK 50维，不按基因方差缩放；Harmony固定theta=2、lambda=1、最多20轮，预设三种种子。所有路线使用同一模型特征、原生计数来源、全RNA归一化及图参数，不把旧启发式结果与新配方的差异单独归因一个参数。

- A：各来源单独PCA/近邻/Leiden细分，保留来源内分群；与B共享的全局对齐表示只算一份几何证据。
- B：全来源联合PCA/Harmony及无监督分群。
- C：先用A的来源内群和冻结的同细胞多marker规则提出粗RNA路由，再在相应粗谱系中联合PCA/Harmony及细分；T与NK共用T/NK路由，混合或支持不足的群保留未决池。输入的作者/旧细标签不充当粗路由真值。

原生整数counts只供HVG和三条路线一致的模型输入。粗路由/状态证据另使用已接受的分析计数层；已有ambient delta不静默取整或撤销。模型与评价层分别记录，不将其区别冒作引擎优势。恶性状态独立，RNA上皮或胶质不自动等于正常或恶性。

评价使用固定的来源×既有粗背景抽样锚点；再按本轮C的粗空间细分这些锚点，让每一对比较使用完全相同细胞，并避免在各自独立PCA坐标之间计算距离。所有细胞、未决路由和小群的覆盖另报，不靠移除不可估计案例改善分数。状态仅使用所有来源共同可测、未进入模型且未用于粗路由的预留RNA基因；低于既定最低基因数则标不可估计。原生计数深度在条件分层内残差化，采用[Scanpy标准Moran’s I](https://scanpy.readthedocs.io/en/stable/generated/scanpy.metrics.morans_i.html)及原有近邻预测相关诊断连续结构；这是本项目的条件RNA诊断，不宣称完整复刻[scIB-E](https://link.springer.com/article/10.1186/s13059-025-03869-z)全部指标。

γδ RNA组合与T粗路由基因有部分重叠，其近邻富集只能作为候选诊断，不作为独立身份准确率。未测保留未知，不补阴性。没有核实的配对TCR/蛋白锚点时报告覆盖限制，不能将RNA marker一致叫正交验证。共用RNA和作者标签的重叠表也不作准确率。

本阶段是全部冻结来源参加的传导式顺序比较；研究留出须在后续单独执行，HVG/缩放/模型只在训练来源拟合，已知或可能重叠研究保留同折。正式选择需结合来源/类型宏平均、稀有/未知、状态与资源证据，不以UMAP、群数或临床P值决定。稀疏counts只在RAM中共享，不给三路线复制计数文件；保存的小型轴、参考参数、表示与状态侧车均受空间/内存门槛约束。

## 独立读回与研究留出接续

独立读回使用另一固定窗口CSR重构逐条复算全部pilot原生RNA总量、采用分析层状态向量、γδ测量资格及同细胞RNA标志；冻结RNA政策共享，不能当独立生物真值。全部保存分群轴和来源内粗路由重放，预定原生PCA探针读回，再按相同锚点重新搜索近邻，并用显式Moran公式和独立相关计算复算所有种子条件结果。官方HVG排序核表与特征资格，本读回不声称重新执行该排序。

研究留出按已冻结的保守重叠研究组执行。每折只用训练来源整数counts重新选择标准HVG、拟合中心化PCA/Harmony和参考分群；C的训练粗路由来自该折训练特征上的来源内A群，被留出研究同样用训练选择的特征进行自己的局部粗RNA注释后映射。没有将全来源共同拟合的细标签作为测试真值。共同候选的来源测量可用性是冻结元数据，不使用留出表达排名。

复用已核SHA的Symphony实现和现有环境，将PCA换成上述官方标准配方。查询批次适配保持参考参数指纹不变；它是冻结参考映射，不假定等同于全来源重整合。每个粗背景比较使用相同训练锚点和相同数值支持查询交集，分别报告未覆盖、小群和未决。粗路由共享RNA不是正交身份真值。A/B共用的参考近邻结果只计一份；分群原型数量未匹配，因此原型预测是解释性探针，不能独自决定赢家。来源内状态迁移统计不解释为患者级显著性。

保存有界私有轴、查询/参考坐标、RNA读出与预测侧车供独立复算；稀疏counts仍只在RAM。所有来源角色与TME资格保持，富集来源仍用于表达比较。
