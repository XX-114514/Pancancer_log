# 连续先验候选的原生发送端、接收端和病例输入

## 固定范围与顺序

承接[全固定程序连续先验](NSCLC-fixed-programme-continuous-prior-alignment-v1.md)。全部1600候选位置保留，各扩展至另外三个原作者发送视图，共4800位置；无候选的位置仍记缺失，不以rank21替换。全部10因子、两方向、四接收视图保持，不使用外部共同变化、功能或临床结果选择。208原始合格病例及145/63分区保持，63曾用于信号保留诊断，不称未经探索独立验证。

本阶段只准备测量、病例分母和RNA资格，不计算发送表达—接收程序的相关、P或临床效果。不得因输入接受便称发现通讯。

## 发送表达与受体RNA

发送表达复用已接受的原生全基因缓存：本病例/作者细胞池的每细胞log1p(10000×count/完整原生RNA)平均值，以及真实阳性细胞数。按真实细胞数加权汇总作者子类型，不用亚型均值等权平均。未捕获与不可测不填零；已捕获且该基因零计数保留真实零。

单基因受体复用完整原生阳性缓存。复合受体按原始细胞逐一核所有亚基count≥1的联合检出，count≥2为敏感性。新候选所需全部复合亚基从已有原始压缩矩阵读取，核完整源SHA；不下载新矩阵，不从边际乘积推断共同表达。保存压缩二值面板、完整病例/池受体计数及固定前缀细胞审核样本。RNA共检出不证明蛋白复合体组装或结合。

## 接收程序与防止直接基因重叠

对每配体，删除配体本身、已有flat先验全部受体和完整参考全部受体的每个亚基；以原冻结A和原prepared-X的剩余入模特征计算接收程序。不重训因子、不重新拟合基因权重或改变符号。与原完整自身分数在145和63病例分别核Pearson≥0.95且RMSE≤原发现SD的0.25，完整程序仍作对照。这里只是测量信号保留，不是生物显著性。

## 资格记录与后续推断边界

发送候选RNA资格要求原145发现病例发送池合并阳性细胞≥1%；接收受体要求原发现病例至少一个已接受字面参考边的同细胞联合阳性≥1%。10%作描述。病例层面所有真实零值继续保存；不按某病例的配体或受体是否阳性删病例，以免选择病例后制造相关。每个候选的每一条参考受体边均记录，不按后续效果挑受体。

每槽记录空候选、发送RNA不足、联合受体RNA不足、接收程序信号保留失败等原因，可同时失败；不把这些原因当负向通讯。初步READY仅说明能进入另行预声明的效果模型。后续应固定完整共同协变量、发送自身程序及组成敏感性、全家族校正和病例级重采样，并将原生内部验证与跨来源扩展分开。尚未运行新效果模型。

## 独立接受与资源

全输入独立核稀疏病例汇总、所有单基因计数、复合亚基二值交集、全部删除后分数及4800槽。有限原始细胞前缀重读范围必须明确，不能称全部细胞独立raw复算。新输出预算128MiB；精确文件系统quota保留500GB加1GiB缓冲。所有学习基因列表、病例和矩阵留服务器，仅公开方法、代码、轨迹和SHA。已有数值审核失败不由本阶段掩盖，旧家族不重开。


## 原生基因缺失的输入实现纠正

先验配体可以通过接收端先验排序但不出现在本队列原生基因轴。发送端可测性是随后检查的条件，不能预先假设所有配体存在。v1在原始矩阵扫描前断言停止；v2保留相同全部候选和位置，对缺失字面配体将发送均值/阳性数存NaN并写明确NOT_PRESENT原因，不以末列索引、零值、别名或rank21替代。单细胞受体和剩余可测发送输入继续；这一实现修正不改变原先验排名或任何统计门槛。
