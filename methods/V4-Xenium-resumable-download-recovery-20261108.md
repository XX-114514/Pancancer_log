# Xenium失败下载恢复与后续中断处理

## 已核实故障

上一轮18份映射全部CRC/长度/既有SHA接受；首份原生输入也已接受并生成技术计算结果。其余5份原生文件均在读取官方ZIP成员时遇到**HTTP范围响应body不足**，不是本轮坐标错误。原下载器的3次范围body重试仍失败，并且只在内存保存最多4块；进程结束后不能重用已经收到的压缩字节。

本轮保留全部旧文件和失败回执，重新下载相同5个成员。18映射与1个原生已重新逐文件SHA和坐标核对，复用，不扩大来源或更改科学参数。

## 可恢复下载合同

1. 在科研服务器持久保存256KiB压缩块，记录源URL哈希、预期归档总长度及块布局；不可把另一来源/另一总长度的数据混入缓存。
2. 只接受HTTP206与精确Content-Range起止和总长、identity编码、足量body；每块落盘前校验长度，并存SHA256。完成元数据原子发布。范围失败不会产生“已接受块”。
3. 读缓存时复查长度/SHA；损坏块保留，新建另一文件取代元数据指向，不删除原件。内存只有少量缓存，不把本地work当长期数据位置。
4. 每个范围最多6次尝试，60秒超时，指数退避加随机抖动、等待上限30秒；支持429与常见暂时性408/5xx。401/403/404/410停止该输入并标记来源/权限待核，不尝试绕过访问。
5. 每轮保留所有已接受块。解压必须从ZIP成员起点重放到**新的**尝试文件，使用既有压缩块；不能把压缩流任意字节直接接到截断h5ad尾部。旧版本没保存压缩缓存，因此其解压残片保留作历史，不能冒充可接续压缩块。
6. ZIP库存长度/CRC、完整解压CRC、独立已知原生SHA及坐标合同全通过后，才生成complete/ready。下载或解压中断只留下partial及失败回执，不进入分析。
7. 采用POSIX互斥锁防止两个恢复进程同时写同一目录；受保护的已接受文件发生变化时停止复核，不静默覆盖。完整文件可幂等复用。

默认单次18小时、3轮；单块6次，失败请求也计入保守字节预算。到期限/轮数仍不完整则exit2，明确列出未接受输入；全部6份接受才exit0。重新执行相同命令复用压缩缓存和已完成文件。没有无限重试、自动Git推送或定时通知。

## 复现与重新启动

源/供者配置和真实路径仅在服务器私有清单；通用代码与脱敏凭据在[任务目录](../inventories/analysis/2026-11-08/v4_download_recovery_v1/README.md)。在部署同SHA代码和原配置的隔离AnnData环境中：

```bash
python scripts/v4_download_recovery_20261108/test_resumable_public_zip_v1.py "${NEW_SYNTHETIC_OUTPUT}"
python scripts/v4_download_recovery_20261108/recover_xenium_downloads_v1.py "${COORDINATE_FIX_RUN_ROOT}" --hours 18 --rounds 3
```

再次执行使用同run根目录和缓存目录；若有活跃writer，应保留并等待它结束。缓存来自私有服务器任务输入，不上传公共仓库。需核对源版本时，保留旧cache另建版本，不能以取消CRC/SHA校验“修好”不一致数据。

## 验证及边界

本机与服务器均通过故障注入：截断、429、范围/总长错误、中断后块复用、完整ZIP成员解压中断重放、缓存损坏重取、全文件SHA拒收、幂等、403和并发writer拒收。原生下载恢复实际已启动，已收到并验证持久块；尚未完成的5份不能称已恢复成功。

首份已有技术计算结果未在本轮做生物学/视觉验收。原分析消费者有独立期限，下载恢复完成后须检查其完成/终止凭据；ready不等于分析已完成，更不等于CM机制已验证。

## 有限接续控制

已另部署`supervise_download_recovery_v1.py`：现有worker持锁时等待，不终止或并行写入。它退出后若仍不完整，才按同目录/缓存重启；默认总窗口48小时、最多3次追加worker，已接受六份则直接结束。已知来源/访问待核标记出现时停止追加，不绕过401/403；达到期限/次数仍不完整则明确exit2并保留缓存。没有无限常驻、日历定时或自动Git。

```bash
python scripts/v4_download_recovery_20261108/supervise_download_recovery_v1.py "${COORDINATE_FIX_RUN_ROOT}" --hours 48 --launches 3
```

控制器在两个环境通过“失败退出后再成功、已完成不重复、活动writer等待、访问失败停止、次数有限、未写完事件不破坏恢复”测试。另已在服务器**独立进程、网络预算为0**的条件下复用一个真实已接受缓存块，验证重启恢复确实来自磁盘。
