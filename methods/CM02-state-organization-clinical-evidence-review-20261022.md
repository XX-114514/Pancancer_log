# CM02状态、组织与临床证据的衔接规则

对象固定为2026-10-14免疫图谱CM02（v1，T_whole_TME_primary_tumor）。本文件承接[原四阶段主线](CM02-specific-states-spatial-clinical-line-20261021.md)，是近期已完成工作的对照与后续准入，不修改原模型、注释、已闭统计家族或正在读取的源对象。

## 三个问题分别回答

1. **状态共同变化**：明确父群、实测状态、病例/材料、癌种、治疗方案和时点。来源内共同变化与某对状态在一般T背景之外的剩余关系分别报告；调整后减弱不等于原共同程序无价值。
2. **组织排列**：先确认父身份及同状态可测，再比较给定双方数量/状态和组织区室后的实际邻域。作者转移类型、RNA阳性规则、连续蛋白和克隆扩增分别定义，不能仅据同名互相替换。
3. **临床增量**：同一明确终点、相同取样时点和真正患者单位；比较预先固定的临床及双方边际基准与新增组合/组织量。术后病理关联、治疗前预测和生存问题分别立项，两个不同队列的不同终点不能拼作同终点验证。

## 下一阶段的执行顺序

- 先跟进[当前独立蛋白输入](../runs/20261022_CM02_clinical_unit_and_source_scope_v1.md)，完整覆盖/官方摘要校验及原生对象通过后，才审患者—组织—区域层级、抗体轴、强度变换及坐标单位。旧工具句柄不可见不当源进程已退出，不另起重复读取。
- 明确整体共同程序与条件配对两个估计对象，保留一般CD4/其他T及组织背景参照。共同程序中的其他成员作为控制会改变问题，不能把条件结果替代原模块结论。
- 若联合面板缺少必要标志，保留类型/区域层面的描述；可另提出局部聚合测量问题，但不能称同细胞状态验证。标签转移与稀疏检出限制均须写明。
- 新组织效果须在实际测量资格后另冻全比较范围、统计单位和空间尺度。当前仅衔接框架，不提前选择真实抗体状态、端点或启动新家族。
- 临床增量以同一合格材料集合比较；不得将旧较小集合与新较大集合的效应差直接归因于新增调整。内部留出与真正外部患者验证分别标记。
- 独立验证首先要求同癌种、可比治疗阶段和同终点；药物/分选差异、重复患者和病例不足明确保留。另一肺癌亚型、另一取样部位或同源多阶段可以是拓展，不自动计独立重复。

## 既有依赖与停止条件

GSE288199 Table S1与GSE243013 RFS更新字段说明为不同依赖；沿用用户已安排的后补节奏，进入RFS效果前提醒，不据数值完整推断事件/起点或启动生存模型。临床列与精确材料连接通过，也不替代患者单位审阅。

若某来源仅满足状态、组织或临床其中一环，该环可单独交付，剩余环记未完成。不得为闭合故事改marker、转移已发表结论、减少必要控制或合并不相同的终点。既有[固定RNA临床](../runs/20261022_HNSCC_observed_marker_clinical_v1.md)、[状态与亚型背景](../runs/20261022_NSCLC_state_vs_author_subtype_v1.md)、[非序列扩增](../runs/20261022_CM02_nonsequence_TCR_measurement_v1.md)和[组织类型测量桥](../runs/20261022_CM02_author_type_RNA_clinical_bridge_v1.md)各按原范围保留。

具体来源级效果、候选优先级和完整对照表仅在已授权私有台账及当前对话说明；公共记录仅方法、过程与技术指纹。此对照没有产生新效应/P/FDR，不重跑旧家族。
