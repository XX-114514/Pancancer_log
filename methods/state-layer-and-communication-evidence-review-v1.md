# 从原9CM到身份内状态：通讯证据卡点与研究设计

## 当前结论

原9CM仍是组成生态模块。多轮检验提供了来源/癌种限定的候选，但尚未形成稳健的“发送配体→接收受体→接收程序→空间/功能”闭环。来源和癌种依赖允许有生物价值，不以缺少全癌种一致性自动否定。正式状态层仍未发布；本报告将事实、解释和未来实验分开。

## 状态标签的设计

**身份回答“这是什么细胞”，状态回答“它此刻在做什么”。** 原172标签、数字和9CM不改，独立sidecar保留多程序连续分数；未知/低支持不得强行填状态。以下是目标字段设计，尚非已发布标签：

|字段|含义|
|---|---|
|major / subcluster / node_id|沿用冻结身份与群编号，不把相同文字后不同数字合并|
|programme_id / programme_version|冻结基因集与模型版本；跨K对应另列，不重复计成独立状态|
|programme_score|连续秩评分；不同程序的绝对分值不直接当生物强弱排名|
|programme_detected_genes / gene_coverage|同cell表达支持和来源可测覆盖；缺失与真0分开|
|programme_RNA_fraction|该基因集占原生全RNA份额，提示稀疏/复杂度/外来RNA问题|
|state_descriptor / review_status|先描述“细胞毒相关”“IFN响应相关”“增殖相关”等；耗竭、免疫抑制、耐药等需额外证据|
|source_scope / inference_unit|训练及投影来源、已审患者或样本替代单位，来源限定明确|

同一细胞可同时有细胞毒、增殖、IFN相关程序；不会按每库固定分位数制造同样数量的“高状态”。Treg属于身份线索和相关功能程序需分开，不能用FOXP3相关模块把所有T细胞改为Treg。

## 模块识别方法如何分工

1. **已实际试点的Spectra/cNMF/UCell**：Spectra利用过程先验，cNMF无先验对照，UCell固定签名投影。五来源240533细胞已经量化评分及数值审核；全18大类100766发现行已审，有限RNA提取v1因索引顺序失败，v2仅只读副本排序恢复。全4532933细胞仍留作流式投影。
2. **SCENIC，后续限定候选**：利用共表达与motif支持的regulon识别调控程序，帮助解释模块背后TF；不是直接LR证据。先对通过模块审阅的谱系做有界对照，避免全库多方法盲扫。[原论文](https://www.nature.com/articles/nmeth.4463)。
3. **PROGENy，后续接收响应对照**：扰动实验得出的响应基因/权重用于通路活动估计；与模块分数形成不同依据，不以某个单基因表达充当通路激活。[官方资源说明](https://www.bioconductor.org/packages/release/bioc/html/progeny.html)。
4. **NicheNet，后续响应驱动排序**：冻结接收程序和可测配体全集后，用配体—靶基因先验评估解释力，减少人工挑LR；先验网络覆盖/共享下游响应限制保留，预测不等于真实直接作用。[原论文](https://www.nature.com/articles/s41592-019-0667-5)、[2025协议](https://www.nature.com/articles/s41596-024-01121-9)。
5. **状态后DIALOGUE和空间**：识别跨细胞类型协调表达程序，再问哪些发送候选与接收程序、空间邻近相符。原组成CM、表达协调MCP和LR轴是不同层，分别编号/映射，不替换原9CM。

## 下一轮怎样避免再走旧路

- 先审状态与测量：原身份内变异、gene支持、来源覆盖、深度相关和跨方法对应；不按LR/临床p挑种子、K或基因。
- 全9CM按冻结成员映射，连未被T/M试点捕获的谱系也纳入；明确共有成员的去重单位。
- 在来源/癌种/组织类别内以已审患者块或样本替代单位聚合。技术/来源控制与真实状态中介分开定义；保留总效应、条件效应及衰减，不把调整后无显著自动写成无生物价值。
- 自动候选全集固定于可测LR数据库与端点，接收模块作为响应结局；解释变量去除接收/发送重叠泄漏，候选特定RNA基因重叠做敏感性而非全局删除。
- 用所有发送候选的联合/留出预测增益及留一配体组变化研究“贡献”，避免仅凭单变量最小p宣称主导CM；共线配体组无法分清单个驱动时报告组级贡献。组内网络和CM活动留一端点估计需共同固定。
- 发现/内部投影/独立验证分别记；本轮已使用来源不会被重新称为独立验证。跨癌种稳定及单癌种有价值线索各自给出证据范围。
- Wilcoxon可回答预定义两组分布差异，但不能自动解决患者重复、来源结构、丰度、深度、共线或端点不可测；改变问题需先固定分组与检验家族。
