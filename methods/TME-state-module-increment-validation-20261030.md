# Frozen TME state-module increment validation

This is a predictive coordination test within the frozen qualified atlas, not a ligand–receptor mechanism or a clinical endpoint test. Parameters are frozen before inspecting held-out-source programme effects. State-feature selection and state-pattern learning use development sources only; the atlas/reference frame already used all sources, so validation is conditional on that frame.

## Observation and opportunity

Use the existing qualification-unit axis and material eligibility. Candidate patient/material blocks are not certified independent patients. Retain absent parents, missing programmes, insufficient cells and ambiguous state projections explicitly. Release identity-context programme means with at least20 cells; primary receiver readouts require40 cells. Fixed native coverage and context applicability masks apply in every source. The source role file, programme list, parent meanings, original annotation crosswalk, and state-model acceptances remain bound by SHA.

## Primary question

For each predeclared parent panel, leave one broad parent out of the sender representation. Predict measured programmes in that receiver parent from the remaining parents. Use all eligible receiver contexts/programmes, not hand-picked communications or programmes selected by held-out significance. No receiver state composition or receiver programme values enter the sender representation.

Compare identical material/receiver-feature domains:

1. A composition/depth baseline containing all measured canonical-identity×numeric-cluster fractions (including low-abundance/fallback children), broad fractions, cell counts and receiver RNA/detected-gene background.
2. The baseline plus sender-only activities of frozen state CoVarNet modules.
3. The baseline plus sender-only coordinates in the frozen continuous-state basis.
4. The baseline plus sender state-pattern fractions as a representation-capacity diagnostic.

Canonical identity and reference phenotype granularity remain separate. No automatic reference state word serves as independent state validation. Programme overlap and source/cancer/material/phase remain recorded; coordinated expression is not proof of communication.

## Fixed inference and comparison

For CoVarNet, infer activity from effective `W S` using only sender rows and the frozen training normalization. Check rank and conditioning of the restricted basis. Below-training minmax origins are nonestimable in the primary projection; an explicit zero-floor sensitivity, if run, keeps out-of-domain flags. Positive extrapolation is not silently truncated. Never fill missing observation opportunity with zero or remove an unidentified module to improve fit.

For a signed continuous basis, use a fixed-basis regularized projection from observed sender views, preserving missingness and the exact training/view scales. Name it as a fixed-basis projection, not as a newly fitted biological state or an exact posterior if posterior inference is not performed.

Use standard ridge prediction with all baseline covariates retained and fixed alpha grid0.01/0.1/1/10/100/1000. Tune on development candidate-block folds only. Evaluate the already frozen representations on held-out sources when enough receiver measurements exist. Development folds are conditional representation diagnostics; they do not become independent source validation because the unsupervised state basis saw development sources.

Report absolute and incremental error, within-source rank agreement, coverage and uncertainty together. Insufficient held-out coverage is nonestimable, not a negative finding. Provide source-specific and cross-context results; do not require all cancers to share an effect. Clinical or spatial validation follows frozen candidates and does not feed back into programme/rank selection.

## Execution order

Accept numerical/scope replay of the developmental state references; prepare held-out fixed-programme readouts without feature selection; accept state projection and independent complete-denominator composition replay; finish state CoVarNet and continuous fits; audit fixed-basis inference and grouped predictive comparison; summarize which coordination information survives identity/subtype and depth controls. Scientific execution, numerical acceptance, biological interpretation and clinical claims are separate gates.
