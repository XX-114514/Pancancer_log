# Frozen TME state-module increment validation

This is a predictive coordination test within the frozen qualified atlas, not a ligand–receptor mechanism or a clinical endpoint test. Parameters are frozen before inspecting held-out-source programme effects. State-feature selection and state-pattern learning use development sources only; the atlas/reference frame already used all sources, so validation is conditional on that frame.

## Observation and opportunity

Use the existing qualification-unit axis and material eligibility. Candidate patient/material blocks are not certified independent patients. Retain absent parents, missing programmes, insufficient cells and ambiguous state projections explicitly. Release identity-context programme means with at least20 cells; primary receiver readouts require40 cells. Fixed native coverage and context applicability masks apply in every source. The source role file, programme list, parent meanings, original annotation crosswalk, and state-model acceptances remain bound by SHA.

## Primary question

For each predeclared parent panel, leave one broad parent out of the sender representation. Predict measured programmes in that receiver parent from the remaining parents. Use all eligible receiver contexts/programmes, not hand-picked communications or programmes selected by held-out significance. No receiver state composition or receiver programme values enter the sender representation.

Compare identical material/receiver-feature domains:

1. A composition/depth baseline containing all measured canonical-identity×numeric-cluster fractions (including low-abundance/fallback children), broad fractions, cell counts and receiver RNA/detected-gene background.
2. The baseline plus sender-only activities of frozen state CoVarNet modules.
3. The baseline plus sender-only coordinates in the frozen continuous-state basis.
4. The baseline plus sender state-pattern fractions as a representation-capacity diagnostic.

Canonical identity and reference phenotype granularity remain separate. No automatic reference state word serves as independent state validation. Programme overlap and source/cancer/material/phase remain recorded; coordinated expression is not proof of communication.

## Fixed inference and comparison

For CoVarNet, infer activity from effective `W S` using only sender rows and the frozen training normalization. Check rank and conditioning of the restricted basis. Below-training minmax origins are nonestimable in the primary projection; an explicit zero-floor sensitivity, if run, keeps out-of-domain flags. Positive extrapolation is not silently truncated. Never fill missing observation opportunity with zero or remove an unidentified module to improve fit.

For a signed continuous basis, use a fixed-basis regularized projection from observed sender views, preserving missingness and the exact training/view scales. Name it as a fixed-basis projection, not as a newly fitted biological state or an exact posterior if posterior inference is not performed.

Use standard ridge prediction with all baseline covariates retained and fixed alpha grid0.01/0.1/1/10/100/1000. Tune on development candidate-block folds only. Evaluate the already frozen representations on held-out sources when enough receiver measurements exist. Development folds are conditional representation diagnostics; they do not become independent source validation because the unsupervised state basis saw development sources.

Report absolute and incremental error, within-source rank agreement, coverage and uncertainty together. Insufficient held-out coverage is nonestimable, not a negative finding. Provide source-specific and cross-context results; do not require all cancers to share an effect. Clinical or spatial validation follows frozen candidates and does not feed back into programme/rank selection.

## Execution order

Accept numerical/scope replay of the developmental state references; prepare held-out fixed-programme readouts without feature selection; accept state projection and independent complete-denominator composition replay; finish state CoVarNet and continuous fits; audit fixed-basis inference and grouped predictive comparison; summarize which coordination information survives identity/subtype and depth controls. Scientific execution, numerical acceptance, biological interpretation and clinical claims are separate gates.

Standard interfaces: [MOFA Python template](https://github.com/bioFAM/MOFA2/blob/master/inst/scripts/template_script.py), [MOFA processing FAQ](https://biofam.github.io/MOFA2/faq.html), [scikit-learn Ridge](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html), [GroupKFold](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GroupKFold.html).

## Frozen implementation details before predictive outcomes

Primary comparisons require at least20 development material observations and8 candidate blocks, and10 held-out observations and8 candidate blocks for a tested receiver programme. Coverage-only exclusions and constant development targets are retained with reasons. A single eligible held-out source yields source-limited evidence; it is not silently promoted to multiple-source validation.

The signed-basis coordinate map uses ridge alpha1, at leastK measured sender programme inputs and nonzero loading information. It records restricted rank and regularization dependence. Infer the fixed K10 coordinate vector before taking coordination-factor columns: the training-only scope criterion is at least1% variance in the receiver broad parent and in an eligible sender broad parent. This criterion is not selected from held-out effects. CoVarNet activity instead requires an identifiable sender-restricted effective basis (condition<=1e8); its bounded KL projection records convergence, and iteration-cap results do not enter the primary predictive comparison.

Each enhancement and its baseline use exactly the same materials and receiver features. Pair-specific domains are retained when another representation is nonestimable; an all-way intersection can be reported separately. Different coverage is not a basis for an accuracy winner. Ridge alpha tuning uses candidate-block-disjoint folds, training-only X/Y scaling, candidate-block-weighted regression and candidate-block-weighted validation error. Candidate block identifiers are scorer/fold metadata and are explicitly excluded from predictors.

The main error increment is programme-macro scaled error improvement after averaging repeated material losses within each candidate block. Use2000 candidate-block bootstrap draws preserving programme missingness. A paired block prediction-label swap/sign randomization provides a descriptive null test under exchangeability of the two model labels within candidate block; it is not an exact general test of all possible equal-risk distributions. The fixed panel×receiver×enhancement family remains open until the CoVarNet, continuous-basis and state-fraction branches are evaluated; final multiplicity correction is not reported from the convenient first-completed branches. Source-specific and leave-one-held-source sensitivity accompany pooled estimates. These are RNA coordination tests, not clinical efficacy or communication mechanism tests.

## Prespecified secondary within-lineage coordination

The primary leave-one-broad-parent test does not exhaust coordination between cell states. Add a distinct secondary family before real predictive outcomes: leave the receiver reference context out, and use other disjoint contexts sharing its supported biological `reference_parent`. Apply this to every eligible context, not only a manually chosen Treg/effector pair. T and NK remain distinct biological reference parents despite the shared T_NK composition denominator; B and Plasma are likewise distinct. Null or unreviewed biological parent entries are not assumed to define a coherent lineage. Single-context biological parents yield an explicit nonestimable within-lineage test.

Reuse the same frozen atlas, programme axes, discovery panels, complete denominators, role masks, material-count minima and regression protocol. Restrict sender state vectors/nodes to other contexts in that biological parent and remove every receiver-context programme/node. Require observed sender information; absent/unmodelled state measurement is not filled as a negative programme. Keep the original composition denominator and control full canonical identity/subtype composition. Fixed-basis and CoVarNet identifiability limits remain in force.

For continuous coordination-factor scope, the training-only1% view-variance rule must support the specific receiver context and at least one eligible sender context. For CoVarNet, retain fixed module definitions and record whether training network members span these contexts. The secondary family and its multiplicity scope are reported separately from cross-parent prediction. Development tuning/held-out evaluation, unknown patient/design limits and RNA-only interpretation remain unchanged. This adds within-lineage state coordination to the full goal; it does not replace an unfavourable primary comparison or promote it to a communication mechanism.
