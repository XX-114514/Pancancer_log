# 固定T表达模式的原生空间测量与描述

对象沿用2026-10-14免疫图谱CM02（v1，T_whole_TME_primary_tumor）的状态落实支线，不修改CM、正式身份或既有闭合临床/空间家族。新的固定RNA模式与此前多基因代理分开，不用旧代理的测量成功代替当前状态资格。

## 测量资格

首先仅读全部既有靶向空间assay的当前基因轴，逐个检查原Boolean模式所需基因的唯一可测性。OR分支的某个基因缺测不能偷偷改为另一个分支；重复symbol不当唯一测量或填零。只读var，不读X/obs/obsm。轴完整也不代表捕获、原始计数、QC、几何、患者、阶段或终点资格。

作者CODEX公开代码中的marker列表只能说明脚本使用过该marker，缺少字符串不等于assay未设计。未知大小的完整表达对象不直接获取；401/403/认证或challenge不绕过、不换链接获取同一受限对象。公开来源各自的数据阶段、RNA/蛋白层和终点分开。

## 全11份公开LUAD作者cell-bin的固定描述问题

继承GSE328481此前完整公开文件库存与全文件SHA，全部11份保留，按字节/URL排序仅为效果前传输顺序，不按表达或邻近效果选组织。当前读取再次检查全长度、ETag、Last-Modified、Content-Range和两端完整SHA；不读取受控GSA、克隆序列、细胞/患者标识或临床行。

保留原六RNA模式及调节/效应父群的全部marker和Boolean定义，主模式直接使用作者保留行的deposited正整数。整数或raw/X与X相同不自动证明原始UMI，不能继承另一scRNA来源的QC500/250/MT20；这里明确为作者cell-bin上的RNA阳性观测模式，不能自动称正式Treg/功能身份。

当前22列在完整原始CSR逐块提取，以独立直接基因索引bincount核每块每列；全观察的向量模式与另一逐行标量规则完全核对。坐标全量有限性检查，相同xy的所有重复行排除，不任意留一个当同一细胞。真实细胞分割/物理微米尺度与患者独立性不由这些检查解决。

## 预定组织关系与参照

全部细胞几何生成有向k近邻机会；主k10，固定敏感性k5/k20，纳入第k距离全部并列邻居、排self，最大跨度为最近其他位置距离中位数的5倍。报告相对原生几何，不称微米。固定最大单邻域4096、总边128×观察数；越界是资源/几何不可估，不改尺度救资格。

三种R×三种E×三k全部27位置保留。每个位置比较R状态阳性与阴性锚点的E状态阳性/阴性邻边，报告加0.5后的四格log odds ratio。它衡量条件于双方父群邻近机会的标记组合，不能当结合、直接通讯或细胞独立检验。

双方父群各≥20；阳/阴锚点、阳/阴接收状态各≥10，且至少10个阳及10个阴锚点实际具有E父群邻居。缺少任一机会保留NA及原因。相同marker在其他T父群中按完全相同几何和门槛计算，R减其他T差值仅在同一图像双边都可测时汇总；其他T不当精确常规CD4。

逐图像先计量，再源级等图像报告中位/IQR、方向数与留一图像中位数范围；不保存逐图像科学表。全部合格四格计数由直接边布尔交集与另一按锚点bincount实现核对。所有尺度与缺资格位置保留，不选择最强图像/半径/marker。

## 推断与执行边界

本阶段不提供P/FDR、病例CI或临床拟合；RNA量/检出量、组织区域及空间相关尚未由该描述设计消除。邻近描述即使一致，也不能证明调节T特异性、原CM活动、同临床终点或预测增量。未来正式推断须另冻可识别背景、空间零模型、患者/阶段/终点和完整机会，并先做方法校准。

客户端至多四个4MiB Range缓冲，用单次只读SSH流入服务器RAM；不在任何一端保存新的H5AD、表达、细胞状态、坐标、邻接或个体/重采样数组。服务器启动前可用内存≥9GiB，峰值RSS≤6GiB。每文件<2GiB，只持久化源级汇总/技术检查点。新输入之前在相同运行环境完成RAM H5AD反向基因轴、完整目标提取和三个尺度与密集距离oracle的并列邻居检查。
