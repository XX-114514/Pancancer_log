# 原生取材组织与测量模态的注释证据

## 为什么增加这一层

补充谱系读数已经完成计算验收。其来源分布触发进一步的描述性核对：癌种来源、实际取材组织和细胞表达谱系可能不同；旧免疫专用映射中的 `unresolved_context` 也可能表示原字典没有覆盖该作者类型。

后续保留四项信息：肿瘤来源、取材组织、细胞谱系与恶性证据。转移灶中的正常组织细胞应按其原生表达和实际组织判断；肿瘤细胞的来源谱系与恶性证据另行解释。不能把来源癌种直接写成所有细胞的器官身份，也不能把缺少旧映射解释为生物学上无法判定。

## 原生上下文交叉核对

从已验收的补充侧文件读取固定线索，核原生行轴、身份轴和哈希，再按原有大类及明确的解剖字段统计。旧大类仍是继承上下文，并非本轮重新接受的标签。

解剖字段采用明确的词表；复合自由文本、癌种缩写、缺失与未审阅值分开。字段不存在不表示对应组织不存在。来源级表保留每项线索的分母，多线索阳性不强行变成互斥类型。原生表达矩阵不再读取或复制。

三项实际反例检查：癌种/混合自由文本不会自动成为取材部位；缺失与未审阅值不混同；同一记录的多线索不会被当成多个互斥身份。全来源输出核每个上下文的总数及各线索交叉表加和。

## 来源模态证据覆盖层

在原来源登记上追加版本化证据，不覆盖冻结试验。原生 `suspension_type`、已有研究设计记录及匹配的公开数据集元数据分别保存。

| 证据 | 使用方式 |
|---|---|
| 全部原生记录为 nucleus，且公开数据集同样明确 | 进入单核分支的来源证据；映射表现仍需检查 |
| 原生记录为 cell | 保留单细胞测量证据，不因平台名称推定其他模态 |
| cell 与 nucleus 混合 | 按记录/文库分支，不以多数覆盖少数 |
| 原生与公开/既有设计矛盾 | 保留冲突，继续核对 |
| 未给出 suspension_type | 不从“10x”或RNA平台名推定单细胞/单核 |

数据集编号匹配不能替代原始下载资产版本核验；核转录组模态确认也不能使富集或预选来源自动具备完整组织组成资格。原患者、阶段、终点与来源别名门槛保留。

三个模态反例检查冲突、多模态/部分未知及平台名误推断。公开数据集元数据来自已有本地缓存，本轮没有下载新生物数据或参考模型。儿童来源不会自动取得成人器官参考的细身份适用资格。

## 对下一步的约束

将基础原生谱系、参考建议、补充线索、作者标签和上述上下文对齐，先记录证据一致、冲突、未覆盖和缺测，再进入来源内局部分群与适用参考补充。线索阳性数量不作为最终细胞类型数量；多谱系支持也不直接等于双细胞。

全量参考证据及其独立审计尚未全部完成时，不提前宣称最终注释或映射验收。后续单细胞向单核的迁移需独立检查，现有来源留出试验不能替代新增技术分支的验收。

## 作者标签覆盖与未决池

作者字段与旧权威大类分别读取。固定词表把明确的细胞名称映射为作者粗谱系上下文；混合名称、marker 后缀、细群编号及未审阅自由文本保留原值，不自动去掉后缀后合并。恶性／肿瘤标签单列为作者恶性描述，不由此推断上皮或其他谱系。

统计旧大类未覆盖、但作者给出明确谱系的记录，以区分字典覆盖问题和表达证据问题。原始值及其词频留在来源私有词表，来源摘要只含固定类别和汇总数。与补充表达线索交叉统计用于定位复核对象；作者标签和这些线索都不作为独立身份真值。

四项实际反例检查非免疫作者名称、恶性与谱系分离、混合／marker 后缀不自动合并、缺失与未审阅值分开。

补充核对发现合并存储使用明确的来源缺失占位符。新版本将这些占位符列入缺失词表，增加第五项反例；旧输出保留，其标签存在量解释为原文本判断下的存在量。联合覆盖表分别列旧口径和修正后的语义缺失口径，不能用占位符计作作者已注释。此修订只处理元数据覆盖，基础谱系读数与参考预测不依赖该存在量。

对多字段来源，还分别核作者标签、标准本体细胞类型和原始群编号。合并后的列名存在不代表每个来源都有相应值；标准本体大类不能替代作者细分状态，原群编号也不当作统一跨来源身份。

## 全量来源内发现的临时分支

在全量基础参考读数、补充线索及两者各自独立审计通过后，沿用已测试的试验粗分支规则，给每条档案记录保存临时分支和理由。新全量来源内细群尚未拟合，局部群支持明确设为不可用，不能把旧标签或作者标签充当新局部群证据。

唯一原生谱系与范围合格参考相符时保留其共同支持；原生单独支持另标临时候选。原生或参考跨谱系矛盾进入来源内待审池；没有局部群证据时，不凭参考单独填补 marker 缺失。补充肝、黑色素及神经／神经内分泌线索继续单列，不覆盖冲突或自动升格为细身份。所有原生行、零 RNA、未决和未获得参考支持的记录均保留。

这一分支文件供后续来源内重聚类和 marker 复核使用。它不是正式注释，不授予模型、组成或临床分析资格，也不将待审比例称为未知细胞比例。
