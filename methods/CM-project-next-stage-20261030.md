# 泛癌多细胞模块下一阶段研究方案

日期：2026年10月30日，Australia/Melbourne。本文是研究设计，未运行新的CM发现、状态模型或临床检验。保留历史结果，承接来源与注释重建、程序分布路线和已有空间算法原型。

建议将主问题收敛为：**在细胞组成相近的肿瘤中，哪些跨谱系功能状态仍然共同变化；这些关系在何种恶性细胞程序和组织情境下保持、减弱或改变？** 泛癌图谱提供发现范围，同癌种独立队列承担复现，空间与功能证据解释具体生态关系。首阶段优先获得一个可信的生物学结论；新估计器是否成为方法贡献，由公平基准决定。

## 一 当前项目的判断与证据边界

用户指出的来源偏倚与注释不足，是当前优先修复的两个环节。仓库已记录文库级资格修订、富集与未富集分支、作者样本桥接、共同身份和来源局部分群的区别，支持这一优先级。但尚没有受控实验量化它们分别解释多少CM变化，不能提前断言两者已经解释了全部不足。

## 三 创新方向的优先级

### 主线 组成相近时的功能协调及其情境依赖

优先检验三个递进问题：细胞比例相近时，状态仍有哪些独立变化；这些变化是否跨不同谱系共同发生；某种预定义组织/恶性程序背景是否改变这类关系。组成均值变化、状态均值变化和关系改变是三个不同估计对象。

例如，T细胞数量与组成相似的肿瘤，可能具有不同的T细胞IFN/细胞毒程序、髓系抗原呈递和成纤维细胞炎症状态组合。这是待验证例子，不预设其方向，也不把IFN或细胞毒RNA强度直接等同有效抗肿瘤功能。只有在同癌种独立来源中复现，且超出一般炎症和测量背景，才具备清晰生物学价值。

“组成和状态解耦”已有相关思想，本项目的新意必须落在**哪个具体跨谱系组合、在哪个情境、改变的是哪条关系、是否产生独立组织或功能后果**。不声称首个泛癌状态模型或首个解耦框架。

### 深入方向 恶性细胞程序连接免疫和基质状态

Spatial EcoTyper的核心SE以免疫/基质类型为中心；把恶性程序作为情境变量提供不同视角，但Pelka已研究恶性—免疫hub，故“加入恶性细胞”仍不够。可优先选择具有共同测量资格的IFN/抗原呈递、缺氧/应激或其他事前定义程序，问它们是否改变既定免疫—基质关系。

恶性身份由作者证据、CNV及正常上皮参照共同审定，低CNV不自动判良性。先在癌种内提取可重复程序，再通过基因集合及外部固定通路对齐可比部分；不强行让所有癌种共享恶性细胞标签。癌种/组织特异程序另列。

需要一项直接关系差异检验，而不是比较两个亚组各自的P值。若使用肿瘤程序作为效应修饰变量，必须核其与来源、组织部位、治疗阶段是否有交叉支持；否则只称可观察情境关联。

### 备选发现 功能组织保持而细胞承担者替换

另一个可检验问题是：跨癌种保留的究竟是固定细胞名单，还是可由不同细胞承担的功能关系？例如相似的趋化/抗原呈递功能可能由不同髓系或基质亚群贡献。此处只是研究假设，不预设任何具体替代已经发生。

构建两个独立层：身份组成网络和细胞类型×功能程序网络。在训练侧固定功能字典与映射，检验来源外功能关系是否保留、细胞承担者权重是否发生直接可检验的改变。需排除注释粒度变化、基因未测、环境RNA和父群捕获差异；用共同父身份、多粒度扰动及独立原生marker核查。相似通路富集或不同cluster名字不能单独证明功能替代。存在同功能但不同承担者的外部组织/功能证据，才可组织为“生态功能冗余或替代”的具体发现；没有扰动时不进一步称补偿机制。

这一方向可能解释为什么强求跨癌种完全相同的CM成员会遗漏结构，也能与固定生态型形成直接比较。但它不能与情境重塑主线同时无限扩展：先按测量资格选一个主要问题，另一个作为备选。

### 方法支线 观测过程与注释不确定性下的可迁移模块

来源制备、缺测父谱系、低捕获量及身份不确定会传播到模块。可研究带测量精度与观测mask的模型、标签不确定性传播及跨粒度稳定性。但mask不能恢复分选前比例，概率标签不能未经校准当真后验；工程修复和统计方法贡献分开评价。

只有在预设的假阳性校准、注释扰动、缺失场景和来源外预测中稳定优于强基线，才升级为方法论文。否则把它作为可信分析基础设施，生物学主线照常推进。

### 暂缓的扩展

不将更大细胞量、更多cluster、更多NMF种子、LR图或一般生存相关作为主要新意。图正则原型保留为实验分支：较低roughness证明正则响应，不能证明生态模块更真实；邻域聚合与图平滑做独立2×2消融。治疗动态必须有同患者配对时间点；横断面阶段顺序不能替代动态。因果驱动需扰动，不从相关边推导。

## 四 数据和注释重建的终点

### 数据按问题准入

建立四类角色：未富集肿瘤组织用于全TME组成和状态；富集/分选材料在相应谱系内研究状态；空间数据用于可测身份/状态的组织验证；同癌种同阶段同终点临床队列用于独立临床评价。snRNA单列协议背景；不能因其不是scRNA就一律废弃，也不能不校准直接混合。

来源表至少含研究、作者材料/文库、患者、解剖部位、原发/转移、治疗阶段、捕获方式、sc/sn与平台、计数层、基因测量mask、QC、重复/复用、各分析用途和开发/验证角色。原始标识与个体表留研究环境。患者未知的材料不能计入独立患者证据。

新增数据优先补“癌种×来源×阶段×组织”的空缺，尤其同癌种多来源，避免追求总细胞数。至少需要可比来源之间的交叉支持，才能区分癌种差异和研究差异；统计校正不能修复完全混杂。

### 注释采用稳定身份加连续状态

固定L1父谱系；在跨来源marker和病例支持充分时发布L2子身份；保留L3作者/局部细群作为细节。状态为独立多维向量，可以同时活跃，不把cycling、IFN或细胞毒性都作为互斥身份。γδT需要身份证据，不能与“耗竭/增殖”放在同一级替代。

每个正式身份附原生正负marker、支持来源/患者、质量与双细胞疑点、置信/未决标志和旧新crosswalk。UMAP用于诊断，不能以混合更漂亮选择最终注释。marker在原生可测表达层核查；整合表示负责图结构，避免把批次校正值当原生表达证据。细分是否值得保留取决于跨来源稳定与生物可解释性，而非cluster越多越好。

冻结一个可用于试点的合格子集即可开展后续测量，不要求全档案所有稀有边界同时解决；扩大范围另发版本。

## 五 最小算法路线

### 1 先建立三个独立数据对象

- C：患者材料×身份组成。保留计数、父分母和捕获mask；全TME比例与谱系内部比例分开。
- S：患者材料×身份×程序的状态读出。先用外部固定字典和训练内cNMF两条受控路线；保留均值、一个预选高分位数或固定阈值活跃比例及测量误差，不把所有读出当独立特征。
- G：独立组织中的状态共定位、区室和边界距离。第一版作为外部评价；若后来进入训练，则另保留未使用的组织验证。

表达程序训练按患者/来源控制细胞贡献，固定字典后流式投射全部合格细胞。使用原生、相容的计数/表达预处理；不能把scVI latent直接当基因程序。拆半和稀释评估状态读出精度，阈值与状态筛选只能来自训练侧，不逐患者重新定义“高状态”而强制同一阳性比例。

### 2 先分清亚型混合与群内状态

对父谱系c的程序g，患者p的均值满足 m_pcg = Σ_k π_pck μ_pckg。固定训练参考亚型比例π_ref，构造m_standardized = Σ_k π_ref μ_pckg。并行保留原均值、标准化均值及亚型组成变化，由此区分混合改变与群内状态改变。

该恒等式适用于均值；分位数不能这样线性相加。缺失亚型不能臆造其均值，应限定共同支持或标不可估。组成调整改变问题，也可能去掉真实生物通路，所以总关联与条件关联并报，不能把条件后变弱解释为原结果必定伪影。

### 3 第一版使用低复杂度状态关系模型

训练侧固定身份/程序、主要读出和精简协变量，在来源内估计患者级状态关系，再以部分汇聚/来源森林图总结共享与异质性。保留负向替代关系。患者多材料作为嵌套重复，不按细胞或ROI数增加独立样本量。

对一个预定义候选关系，可采用：

```
S_receiver = α_source + β S_sender + θ C + η Q
             + δ T_context + γ (S_sender × T_context)
             + patient_effect + error
```

C是与问题匹配的有限组成变量，Q是测量质量，T_context是预定义的组织/恶性程序；patient_effect仅在重复结构支持时使用。β和γ分别描述关联与效应修饰，不代表因果。比较含交互与不含交互的外部预测，并报告γ的区间。不能给每条边无限追加协变量；来源很少时随机效应方差也不可靠。

网络发现为探索阶段；正式关系检验须在留出来源或新的独立来源执行。完整程序向量按患者一起置换/重采样，置换在可交换的来源/情境块内进行。连续协变量残差置换需模拟校准。检验家族事先定义，统一FDR并保留不可估边。

### 4 只有低复杂度基线不足时开发联合模型

候选模型可写成组成计数的多项/logistic-normal层与状态读出的误差层，共享患者因子、允许视图特有因子，癌种/阶段载荷采用收缩偏移。状态误差含测量方差与生物残差；多分位数需估计协方差。观测mask只限定可见条目，不对未知选择机制做自动修正。

必须固定参考/尺度和可辨识约束；不同时自由改变所有情境载荷与因子协方差。稀疏惩罚不保证可辨识。若采用非负W且列和为1，W的L1范数恒为K，该惩罚不产生稀疏选择。训练集决定rank、参数和特征；测试集仅投影，不能使用临床P值挑模型。

| 同输入的最小修正版 | 分离mask、分母和训练泄漏修复收益 | 与原模型相同任务和预算 |
| Pelka式分布网络、DIALOGUE | 检验状态输入是否已经解决问题 | 同患者/程序可测域的跨类型协调 |
| 多细胞MOFA/mc-ASTRA；适用时MuVIcell | 强多视图基线 | 目标视图留出预测、来源迁移 |
| 新情境/测量模型 | 证明额外复杂度必要 | 误检、校准、注释敏感性与迁移 |
| EcoTyper/Spatial EcoTyper冻结参考 | 判断发现与既有生态型的重叠及增量 | 可测范围内的映射、组织解释和额外预测 |

EcoTyper、Spatial EcoTyper和组成网络的原始输入不同，不能直接比较各自训练重构损失；共同任务使用共同可测域，额外覆盖域另报。scITD/MANTRA作为张量路线的相关方法与可选比较，不强行把所有工具塞进第一版。

模拟至少包含：无真实协调但有来源均值差异、共同分母变化、亚型混合而群内无变化、真状态协调但组成不变、情境效应修饰、富集/缺失、注释拆分合并和重复患者。加入不符合候选生成模型的场景。评价边/模块恢复、经验误检、区间覆盖、注释扰动、测量稀释、资源成本，不用“更多显著结果”评价。

外层优先同癌种留一研究，再留一癌种；所有参考学习、缩放、参数选择在训练内。已有反复探索的队列标为开发暴露，不能事后改名外部验证。测试目标状态不能参与患者因子估计后再被“预测”；需用其余视图推断活动，或留出独立基因/模态。

空间验证采用病例层推断、区室内参照和合理局部null，控制密度与自相关；空间块划分防止重叠邻域泄漏。不把训练图平滑后的Moran's I当独立成功。恶性程序与邻近免疫状态同一病理位置的关系需要直接测量；跨患者同癌种匹配不能假装成配对组织。

机制深化先核不重叠的接收功能读出，再做完整可测LR的受约束分析；LR表达和空间接近仍是候选机制。若后续有实验条件，可预设候选配体/接收轴的扰动与救援、空间或功能读出。临床放在同癌种/阶段/终点的外部评价，比较临床基础、组成、单端状态与组合，报告校准及预测误差；仅关联时按关联结论交付。

## 七 工作包与阶段门槛

以下为建议的人力排期，数据准入和试点吞吐未验收前不承诺计算完成日。

| 顺序 | 工作包 | 产物 | 完成后决策 |
|---|---|---|---|
| 第1周 | 来源/注释小范围冻结，来源×注释四格诊断 | 可复核角色清单、共同父身份、crosswalk、变化归因 | 确定可信发现范围；不足先补同癌种来源 |
| 第2周 | 在1–2个覆盖合格癌种做状态测量试点 | C/S/mask、拆半/稀释、基因字典与测量误差 | 只有可靠读出进入网络，尾部不可靠不强保留 |
| 第3–4周 | 组成、分布网络、DIALOGUE和多视图基线 | 完整基线结果与留出预测、有限状态关系 | 基线已足够则优先生物学，不开发复杂新模型 |
| 第5–6周 | 同癌种独立复现与情境关系检验 | 预定义候选、方向/区间、直接交互/差异检验 | 稳定关系进入恶性/空间深化；来源限定结论保留 |

## 八 立即行动与停止条件

立即交付三个接口：source_role_registry、identity_state_crosswalk和patient_view_manifest。每项绑定版本、来源键、测量mask和患者划分；不重新建设一个无边界的大而全图谱。现有来源/注释主线继续；状态测量可在已合格子集先行；CM02旧支线不因本方案恢复已暂停的临床/LR任务。

停止条件：来源与癌种完全重合时不估癌种特异重塑；读出不稳定时不做高维网络；只有重构改善时不宣称方法突破；仅均值/丰度改变时不称关系重塑；未做扰动时不称驱动。若跨癌种推广不成立但同癌种组织关系可重复，收敛为有范围的生物学发现。

新颖性来自经证据支持的具体发现和可重复改进，而不是上述组件的组合名称。本轮结论是研究优先级判断，不是穷尽文献后的首创证明。
