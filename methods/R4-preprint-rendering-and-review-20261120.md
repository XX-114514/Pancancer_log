# R4 预印本绘图与双语稿件复核

本轮只把冻结科学结果组织成可审阅图稿，不以重新选标签、重拟合嵌入或重做显著性获得更好图形。原生键与冻结计数对齐后，统一坐标用于全部图谱视图；原生 marker 汇总使用完整文库归一化及逐基因合格分母，另用独立审计输入复算。私有源表和科学解释保留服务器。

## 文稿构建

[通用构建器](../scripts/r4_preprint_20261120/build_manuscript.py)从外部私有 JSON 读取双语章节、引用及图注；其本身不包含稿件内容。英文与中文共享同一套英文科研图。默认使用简洁学术样式，页码、黑色标题和完整图注；移除默认模板装饰性段落边框。

使用 Codex 捆绑 Python 与 LibreOffice/Poppler 渲染工具。为 CJK 使用已有可用字体及任务独立 fontconfig，配置字体目录与可写缓存，不修改全局配置、不随稿件分发商业字体。生成 DOCX 后运行 documents 技能的 render_docx.py，逐页检查 PNG；确认无缺字、溢出或图注孤页后才交付。

[补图合册构建器](../scripts/r4_preprint_20261120/package_supplementary_figures.py)保留独立图的矢量页面，以新增页高承载英文图注，避免裁切已有图。其私有图注也通过外部 JSON 输入。

## 证据与展示规则

图中缺失/不可检验不填零或画为检验阴性。固定候选与设置说明随图保留；重复模块成员、同一队列多模型、同一切片多参数不计作独立重复。所有森林图区间必须来自已有合格模型；不把 posterior abundance q05 当作相关系数置信区间。

每次交付保留代码版本、输入与输出 SHA、逐页复核状态、失败修正记录和服务器副本回执。文稿为作者审阅版；公开发表、作者信息及数据公开方案仍须作者另行决定。
