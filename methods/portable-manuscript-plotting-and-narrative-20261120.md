# Portable manuscript plotting and narrative

A manuscript figure has one declared argument role. Biological results set the main order; version history, execution incidents and full qualification records remain in their own documentation. Measurement definitions, frozen estimands and complete comparison families remain traceable when narrative emphasis changes. A per-location editing register links the prior prose to its replacement.

The portable plotting package contains aggregate tables, identifier-free coordinate/category arrays, dictionaries and relative-path configuration. The assembler runs three rendering branches, copies the declared figure IDs and hashes each output. Frozen coordinates and statistical values are reused; plotting performs no inferential refitting. Display arrays carry no native row indices, cell barcodes or individual patient/sample identifiers.

The input verifier checks byte size, SHA256 and path containment against the external input manifest. Document builders consume external bilingual content. Rendered pages are visually inspected; a figure-only correction is rerendered through the shared plotting function. Full image rendering and a runtime scope smoke are recorded separately, and smoke artifacts never enter the review package.
