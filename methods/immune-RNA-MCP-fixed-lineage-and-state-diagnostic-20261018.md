# 固定交叉谱系RNA与独立状态读出诊断 v1

## 目的

在394位置的关联家族不改动的条件下，核查MCP的细胞来源解释。使用同一冻结19,018细胞、全部三视图/三来源/两程序，不因某条分子关联强弱选择细胞或基因。新诊断不更新原注释、不自动删细胞，也不重写主P/FDR。

## 固定输入与描述

读取公开固定的T核心3、髓系核心6、B核心4、上皮4、既有IFN6/增殖5及即时早期15基因，共43基因的原生计数、完整RNA分母及可测量状态。谱系共表达阈值依次为至少2/3、3/6、2/4、2/4原生阳性；缺基因记不可判，不把缺失填零。它们是RNA捕获标记，不是双细胞分类器或正式身份判定；阴性也不能排除技术混入。

每视图各来源完整报告固定标记的可测量/共表达计数，以及IFN/增殖/即时早期的平均log1p(CP10K)与两MCP的样本级原始/质量调整点关联。IFN/增殖基因在本次MCP训练中已排除；即时早期集与学习程序可有重叠，因此不称独立读出。无新的P/FDR或状态阳性命名。

另给原标记集合补集的18个协调点敏感性：T视图关注髓系/B/上皮共表达，髓系视图关注T/B/上皮共表达；每个标记全可测且没有上述共表达才进入补集。保留每样本剩余细胞数，双方至少20才有该敏感性。原程序权重、原nuisance变换及原发现节点效应保持，按补集细胞重新求均值与节点组成预测；双方RNA/基因质量取补集均值，完整视图比例/计数保持原定义。主前后点效应使用相同可比较样本，不给新区间/P。该集合不是重估后的“纯细胞”人口，不能当新丰度或因果纠偏。

交叉谱系RNA可以来自混入、环境RNA、吞噬或真实复合体，单靠本次RNA不能区分。原始实验支持[血液T–单核细胞复合体](https://elifesciences.org/articles/46045)及[PIC-seq的物理互作细胞](https://www.nature.com/articles/s41587-020-0442-2)，但这些不证明当前肿瘤数据存在同一机制。若诊断改变解释，将另规划接收功能/物理证据，而非选择性移除细胞求显著。
