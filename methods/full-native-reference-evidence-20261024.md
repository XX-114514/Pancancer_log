# 完整原生档案的首层参考与多基因证据

## 作用与范围

使用已接受的 NativeArchiveCollection 全部已选来源记录，包括此前未进入比较集合的记录。这个节点提供全量逐细胞证据，后续继续来源内分群、参考范围扩展、共同身份和模型映射；当前不发布最终注释。

复用已验四个参考及多基因规则，固定文件与模型参数指纹。免疫参考只对具有原生免疫线索或继承免疫粗标签且原生 RNA 为正的细胞提出预测。已有器官参考在已审来源中限制于原生非免疫候选；没有适用参考的细胞保留原生证据和明确缺项，不能因参考范围空缺直接宣布生物身份未知。其他已缓存器官参考须进一步核对适用范围和标签字典后扩展。

## 保存内容

保存原生行轴、身份轴摘要、总 RNA、多基因检测压缩位图、谱系/细类型候选支持位图、六类连续 RNA 程序及测量覆盖，另保存参考最佳/唯一候选编码与多标签状态。完整预测概率矩阵和原生 counts 不写盘。参考最大分数不是校准身份置信度。

作者标签继续存于原生源，保存字段和覆盖；QC/排除/污染/刺激等已有状态保留逐行编码和原始值字典，字段不存在不改为 False。档案成员、模型资格、组成资格和临床资格分别处理。没有从相互冲突的 marker 自动诊断 doublet、污染或恶性。

## 验收

分块使用全部原生基因的 RNA 分母，未测 marker 保持测量掩码；不足三个已测程序基因时程序不估计。每来源完成后读回所有紧凑字段，核原生行/身份摘要、参考指纹及记录数量。对已审 pilot 交集复算原先预测；器官参考范围变化单独注明并只比较共同范围。完成首层后仍需独立复算及完整注释资格，不用计算完成代替生物学验收。

运行前刷新实际输出文件系统的组硬配额和物理余量，结合有界输出上限、工作区及已在运行任务判断。大型 counts 物化沿用独立的预留与峰值门槛；本阶段不生成全量 counts 副本。

## 独立验收的覆盖

独立程序逐来源核全部行轴、身份摘要、档案成员、作者标签覆盖、QC 原始编码、测量掩码、参考范围和输出分母；从压缩检测位图重新推导所有多基因支持规则。每个来源按固定均匀位置加零 RNA、参考范围、档案成员和多/无匹配等边界抽取记录，独立读取 CSR 跨度并复算原生分母、marker 检测和状态均值；参考结果调用官方 API 复核。

为及时发现实现错误，在生产继续时可对已有不可变完成记录执行明确命名的来源预验收；这不代表全部来源验收。正式验收需要生产真实退出零后核完整索引与所有来源。本验收不声称第二次遍历全部原始表达，也不把计算一致性当作独立身份真值。
