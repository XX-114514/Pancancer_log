## 层级

| 层级 | 含义 | 来源 |
|---|---|---|
| L1 区室 | T/NK、B/浆、髓系、肥大、pDC、中性粒、成纤维、周细胞/平滑肌、内皮（血管/淋巴）、上皮、间皮、黑色素细胞、胶质/神经、肝细胞、骨/软骨、脂肪、骨骼肌 | 全局 Leiden 簇 + L1 面板，人工核实 |
| L2 类型 | 例如 CD8_exhausted、macrophage_SPP1、fibroblast_myCAF、AT2、colonocyte | 区室内重新聚类 + L2 面板 + 差异基因 |
| L3 状态 | 增殖、ISG、应激/解离、缺氧 | 附加标记，不替代类型 |

## 流程（每个区室或每个待处理大簇相同）

1. **取子集与读取**：从 TME 分片按数据集连续块读取。保留共同基因和面板基因；某来源没测到的面板基因记为缺失，不当作0表达参与判断。
2. **重算特征**：在子集内按来源计算 seurat_v3 HVG（3,000个，去除技术基因），PCA 50，Harmony 来源 θ2，15近邻，Leiden 0.5/1.0/2.0 三个分辨率，UMAP。
3. **每个子簇的证据表**：
   - 面板基因的平均表达和表达比例，对子簇做 z 分；
   - Wilcoxon 差异基因：每簇最多取2,000个细胞，报告 logFC、表达比例差和 FDR；
   - 跨来源可重复性：同一 marker 在贡献 ≥50 个细胞的来源中分别做簇内对簇外比较，记录上调来源所占比例；
   - 组成：来源数、最大来源占比、癌种、样本数；
   - 恶性证据：uncertain 占比、cnv_score/cnv_corr 中位数、scATOMIC 预测分布；
   - QC：基因数、UMI、MT%、decontX 污染的中位数。
4. **按顺序判定**：
   1. **低质量**：基因数中位数 <500，或 MT% 中位数 >20 而且没有特异 marker → `low_quality`。
   2. **双细胞**：两个不同谱系的 L1 面板同时 z ≥1，而且簇内超过30%的细胞同时表达两组谱系 marker → `doublet_like`。
   3. **红细胞**：erythroid 面板占优 → `erythroid_contamination`。
   4. **L1/L2 命名**：面板最高分 z ≥1，并且同一 L1/L2 至少有2个面板基因进入该簇差异基因前50。名称格式为 `<类型>_<代表基因>`，代表基因取跨来源可重复性最高的那个。
   5. **证据不足**：面板与差异基因不一致，或最高分不够 → 保留簇号，记为 `unresolved_<簇号>`，并写出 top 差异基因，交给人工复核。
5. **置信度**（证据分级，不是概率）：
   - high：面板与差异基因一致，且 marker 在 ≥50% 的贡献来源中上调；
   - medium：两者一致，但可重复来源 <50%，或该簇只来自 2–3 个来源；
   - low：只有面板或只有差异基因支持。
6. **来源特异性**：最大来源占比 ≥80% 或 <3 个来源 → 标记 `source_restricted`。保留命名，但不能单独作为 CoVarNet 节点，需与同类合并或复核。
7. **CoVarNet 节点资格**（初步）：L2 类型满足：≥3个来源、≥20个样本、该类型在样本中的中位细胞数 ≥5、置信度不为 low。

## 待处理大簇（全局 Leiden 簇13，290,546个细胞）

- 簇13的 uncertain 占76.5%；非恶性细胞约6.8万个。
- 先对整簇（含 uncertain）重新聚类，以便看出非恶性细胞是否自成子簇。
- 每个子簇判断它属于哪一类：
  - 组织来源的正常上皮（用 L2 上皮面板确定器官）；
  - 间皮、肝细胞、胶质等非上皮；
  - 低质量或双细胞；
  - 与 uncertain 混合、CNV 偏高的"疑似残留肿瘤"子簇。
- 对"疑似残留肿瘤"子簇，即使其中细胞被判为 non_malignant，也列出给用户决定是否从 CoVarNet v1 排除。本步骤不自动更改恶性判定。
