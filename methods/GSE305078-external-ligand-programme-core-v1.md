# GSE305078来源限定配体—接收程序检验v1

## 效果前范围

使用已验收的全部原细单位、固定基因程序/调控读数和官方阶段sidecar；不合并细节点，不读临床疗效，不变更原2026年10月CM（v20261010）、172身份、旧P/BH或原严格设计失败。原作者细状态与当前图谱节点尚未精确映射，本轮属于谱系扩展及跨来源一致性检查。

四个原分子定义去重复家族的全部234个细胞对，在两个官方阶段各留一主要masked接收程序槽，共468槽。另对发现来源选定的一个家族/调控因子组合保留全部104细胞对×两个阶段的208功能槽；该选择在外部效应前写入私有配置并锁SHA，不依据外部结果换TF或细节点。完整676槽统一BH，不可估计内部P=1，展示缺失。晚期样本不足不转入早期扩大分母。

## 样本、指标与完整核心控制

每文库同一原发送/接收节点各>=20原细胞，主设计>=20文库、有效残差df>=10，发送配体至少10文库实际检出。分期、组织和原GSM/title来自官方精确sidecar。文库替代单位不是已审患者；重复采样身份未正式晋级，所有置换/重采样按文库单位解释。

X为发送配体原生mean per-cell log1pCP10K；Y为原固定masked接收基因分数，或预选调控靶RNA模式。秩化X/Y，连续控制在当前可比集合标准化。核心控制固定为双方大类内比例、log1p细胞数、mean log1p全RNA及mean log1p检测基因（8项），加接收者自身配体、原固定受体集合最大RNA阳性比例（2项），保留截距。原受体组分未测/复杂受体同细胞RNA不可得时保留不可估计，不用边际比例冒充复合物。原受体集合在接收群池内至少一项>=1%原生RNA是输入门槛，不按效应换受体。

原冻结权重、均值/SD和mask不重学：保留>=80%原L1、剩余>=95%可测及>=20基因。功能跟进额外要求原固定去基因靶/背景各>=95%可测、>=20靶/500背景；这只定义新外部范围，不回写原功能评分或P。

本轮完整临床控制不可恢复，因此不称年龄/治疗等完整调整或临床预测。用原发现数据中同样10项核心控制另做完整已选父记录的描述性桥接，不重算其P/BH。原完整18项结果与新核心模型分别保留，不混称相同模型。

## 可识别性与推断

SVD保留完整核心控制矩阵的数值列空间（相对阈值1e-12），不依据效应删项。常量/重复列仍完整记录；不解释其非唯一系数。只有秩化X在该空间外有非零残差、有效设计条件数<1e8、df>=10、最大杠杆<.999999时，候选系数才可识别。另报告原12列严格满秩是否满足，不能将新投影方法覆盖旧严格门槛。参见[statsmodels关于广义逆和秩缺陷的限制](https://www.statsmodels.org/stable/pitfalls.html)、[SciPy SVD定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.svd.html)。这些文档不替代本地数值和零效应校准。

主要统计量为完整控制空间后的HC3学生化系数，报告partial rank rho。零假设下以restricted residual / sqrt(1-h0)作文库Rademacher wild bootstrap，固定199999次，不因结果接近阈值追加；该检验是小样本模型近似而非精确随机分配检验。每槽固定种子，报告超越次数及全家族Monte Carlo上界BH敏感性，不能把模拟精度当生物真实性。完整676槽BH与BY并列保留。

2000次文库pairs bootstrap重排X/Y秩并重算控制空间，至少1800有效才给区间。全部留一文库的描述性rho重算，保留失败；该描述只需可识别，原主要df/阳性文库门槛不在删一后重新选择人群。额外加入原发送程序，功能槽另加发送同调控签名，只作共享程序敏感性，不新增P家族。

独立输入审计、合成full-rank/常量重复控制/X不可识别、statsmodels HC3和显式wild拟合对照完成后才执行真实检验。零效应模拟用于诊断近似，不从通过与否挑有利参数。完整点/区间/所有随机次数/留一及BH须另独立复算。科学结果与样本/学习基因权重只服务器和获准当前对话；公共仓库只有方法/过程/指纹。
