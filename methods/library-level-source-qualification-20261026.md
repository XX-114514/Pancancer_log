# 按实际样本或物理文库登记来源资格

本规则由项目研究问题提出，不代表原研究作者采用过同一张筛选表。原始档案、当前分析集合和临床准入分别维护。

## 登记单位与证据

每条资格记录保留研究/GSE、原生表达单位、原始文库ID、生物样本ID和患者键，记录各自的证据级别。物理库、技术通道、生物样本和患者不能自动等同。缺少物理库桥时保留表达单位身份；不能通过命名样式或细胞数替代原作者对应表。

字段至少包括癌种、原发/转移/正常或癌旁、器官和材料、新鲜/冻存、scRNA/snRNA、分选/富集方式、实验捕获区室、输入数据保留区室和治疗阶段。实验分选与作者/项目计算筛选的子集分开。器官名称不自动说明肿瘤受累；单核测量不自动说明冻存；测序平台不自动说明细胞或细胞核。

分选证据按原论文Methods、官方样本元数据、制备说明或作者实验记录登记，并注明适用于整个研究还是特定文库。高T细胞占比不用于推断T富集。FACS活细胞筛选、去红细胞与CD45/CD3/CD8等谱系富集不混为同一流程。

## 按问题分层

| 材料或设计 | scRNA肿瘤组织全TME主发现集 | T细胞内部问题 |
|---|---|---|
| 未富集肿瘤组织 | 条件候选，复核区室保留和样本资格 | 同材料/阶段内条件候选 |
| CD45或淋巴细胞富集 | 排除未加权多谱系主发现 | 核T亚群捕获后条件纳入 |
| CD3或T细胞富集 | 排除 | 同捕获范围内条件候选 |
| CD8富集 | 排除 | 限定CD8内部 |
| 分选区室混合 | 原位混合权重未恢复时不直接纳入 | 保留分选层并核T亚群选择 |
| 血液、骨髓、体液 | 各材料另设集合 | 各材料内部另设问题 |
| 正常/癌旁 | 单独对照集合 | 单独材料对照 |
| CAR-T制造产品 | 单独产品集合 | 产品T细胞状态 |
| 离体刺激或培养 | 单独实验集合 | 实验状态问题 |
| snRNA | 与scRNA分别建模 | 保留单核分支 |
| 仅保留非恶性或指定谱系的数据文件 | 不作为完整TME分母 | 根据实际保留范围限定问题 |

同一研究内总组织与富集分支并存时，按样本/文库对应分别登记；不因存在一个富集分支删除整个GSE。研究内一致的制备步骤可以继承，但必须与该输入分支对应。

## 结论与复现

筛选建议使用“排除本用途”“待核实”“条件候选”等明确状态。“条件候选”不等于最终资格通过，仍需区室完整性、QC、重复取样、来源别名及与分析问题相符的身份/患者资格。未审阅患者键不能计作独立患者。

[规则实现](../scripts/library_source_qualification_v1.py)与[反例检查](../tests/test_library_source_qualification_v1.py)固定以上问题边界。文库明细和研究内患者/样本键保存在私有交付；本方法不包含这些记录，也不改变原始计数、权威身份或既往带日期的CM版本。
