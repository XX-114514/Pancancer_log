## 对象中各层如何使用

| 字段 | 含义 |
|---|---|
| `layers['counts']` | 发布源计数，按可信稳定基因 ID 合并同基因别名，int32 稀疏矩阵；作者发布前可能已经处理，不能一概称未校正液滴原始计数 |
| `layers['ambient_removed_counts']` | 仅实际采用的 DecontX 去除差值，float64 稀疏矩阵；未采用的诊断估计不会扣除 |
| 分析计数 | `counts.astype(float64) - ambient_removed_counts`，按块计算；不必物化全量新层 |
| `X` | 从分析计数重新按每细胞总量 10,000 归一化，再 log1p，float32 稀疏矩阵 |
| `obs.analysis_count_origin` / `analysis_correction_applied` | 明确哪些细胞采用校正、哪些保留发布源计数 |
| `var_names` / `var.gene_symbol` | 稳定身份键与代表名称；绘图用名称，连接优先用身份键。49,985 特征含 400 个歧义及 1,244 个仅名称键，未伪造唯一稳定 ID |
| `varm['measured_in_source']` / `uns['source_order']` | 各来源是否实际测量该基因；未测量的补零不能当真实零表达 |
| 原始来源及 QC/复核字段 | 原 ID、作者标签、技术、组织、富集/产品背景与过滤原因；局部模型诊断簇不是全局细胞身份 |
