## 6. 下一步的优先次序与判定标准

1. **先完成六例身份和组织学审核。** marker图保留基因+对应身份；优先看稀少NK、T/NK近邻、异源程序/分割混合和低RNA检出性；蛋白/未用于门控的证据补充。不能按空间P反复改marker门槛。
2. **把内皮质心代理升级为可靠血管对象/区室。** 多marker区分血内皮/淋巴管及静脉背景，CCL19/21阳性细胞先按完整谱系确认Mural/Fibroblast等来源；不直接命名HEV或周细胞。匹配组织区域、TLS、血管量和局部淋巴密度，以患者汇总。
3. **判断B/NK组合是否有超出总体浸润的增量。** 比较目标与对照血管的B/T/NK组成、距离梯度及B/T、NK/T背景，保留25/50/100/200μm全尺度。不把所有细胞靠近血管当特异性；B—NK不是原边，三方同一邻域是扩展问题。新增正式比较须另登记，现有内部组成仅描述。
4. **通讯只跟进身份和邻近位置支持的轴。** 原CCL19/21–CCR7、CXCL12–CXCR4全部候选与NA保留；来源表达、三组区域和局部固定几何零模型共同看，患者单位与全家族校正。当前0 BH不能靠挑名义P、加状态或只重跑阳性边挽救。
5. **空间指标固定后再做临床增量。** 对照血管量、总免疫量、B/T/NK单独量及TLS，治疗交互与预后分开；新空间特征在未用匹配队列确认。现有TCGA/ICI只提供背景，不继续泛癌筛P找替代故事。
6. **新清理TME独立重跑CoVarNet并对照旧发现。** 去免疫富集来源、细化注释后做来源/癌种/患者隔离和稳定性比较，保留原结果。若NK增量不足，可收窄为血管相关B/T组织问题；若连结构增量也不足，回到输入/注释和新发现版本，不强维持CM03三方生态位。状态仅在解释明确结果时补充，不作推进前提。
