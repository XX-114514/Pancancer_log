## 是否在后续合并时又放回来了

逐一读取54个原QC过滤后H5AD，按每个来源的原细胞名对齐当前V7；另一套审计用完整排序后的ID多重集和唯一性重新核对。结果：

- 全4676787个细胞与原QC过滤后对象精确一一对应，54个来源的细胞全集相同。
- 全部历史doublet分数逐细胞一致，包括缺失值。
- 原过滤后对象的`predicted_doublet=True`与`doublet_removed=True`在当前V7中均为0；旧队列的`filter_reason`均为pass。
- 另从旧31来源的2148018行原始逐细胞QC账本重算：5518触发doublet排除，5177仅因doublet排除，与原汇总一致。

这证明历史筛选被当前V7/core继承，未发现已剔除细胞重新进入此细胞轴；不证明保留下来的细胞全是真实singlet。[54来源逐项核对](source_membership_checks.tsv)、[独立审计](independent_audit.json)。

## 确实存在的覆盖缺口

28999细胞（约0.62%）没有原始Scrublet分数，且与`doublet_status=not_run`精确一致。旧队列对应102个小样本单元，新增13个，共115个；这些单元低于当时500细胞启动门槛。原代码实际返回NaN分数与False占位标志，**并没有完成“只打分不去除”**，不能将False解释为有效singlet判定。状态列是执行状态，原预测列才是工具判定。

未运行细胞涉及Tcell 6284、Bcell 3025、Macrophage 2507、Mast 218等；Tcell_6中786、K-09中7。可据[全部来源](not_run_by_GSE.tsv)、[全部父类](not_run_by_major.tsv)安排后续补查，不能因为总量占比较小就自动判为合格。
