# WEHI R4作者图像：相对几何检查

三种统一的纯图像检测方案与固定几何门槛下，6片得到相对外框网格，mel1_rep1和mel4_rep2不合格。**这不是条码坐标或H&E配准完成。** 没有用RNA或CM强度选择变换，也没有据此增加血管定位、患者独立性或生物学结论。

相对33×35网格是假设范围；6片工作图RMS误差2.629–3.317像素，留边最大误差6.287–9.134像素，不能转换为细胞级定位精度。独立标准库重放12个几何候选，最大数值误差5.51e-12；证明派生计算一致，不证明图像锚点真值。

初版黄色阈值在黄色背景上误检，严格门槛漏掉暗边，局部对比改善部分边缘。全部方案、伪候选和失败保留。旧拟合状态把失败泛称为“缺完整边界”过宽，当前逐阶段记录实际拒绝原因，验收门槛不变。

公开文件仅几何候选、诊断和代码模板；原始图和候选叠图留服务器，未上传原始人类图像。模板需配置ANALYSIS_ROOT及原分析输入布局。继续组织学验证需独立核对条码原点、方向、spot非均匀位置及H&E变换。
