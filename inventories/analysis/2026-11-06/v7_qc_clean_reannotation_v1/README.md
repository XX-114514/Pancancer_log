## 决定依据

已有联合条件（父类支持、竞争程序、原记录样本/检测方法内doublet分位≥.95）之上，再要求不同谱系两组组件均有正向RNA锚点，并满足≥3个marker各≥1UMI或≥2个各≥2UMI。T6的845个联合候选分为783剔除、62暂存；Mast1323分为1150剔除、173暂存。K-09的245分为227剔除、18暂存。

全V7原28,999个not_run细胞按115个完整记录QC单元补查，96个单元做三种子Scrublet，19个不足100细胞。288次拟合均数值完成；27个单元/7,711细胞达到本项目稳定性门槛，69个单元/19,962细胞的阈值或可检测性待复查，19个单元/1,326细胞仍不可评估。不能把后两组当作模型阴性。

稳定单元出现35个3/3阳性候选。逐单元检查三种子观测/模拟直方图后，16个无预处理数值警告的阳性单元共34细胞采用为补充剔除；一个有invalid-log警告的单元共1候选暂存。34个补充剔除均在本轮T6/Mast之外。稳定性与阈值门槛是项目复查规则，不是文献统一概率；样本单元来自现存QC保留细胞，未重建原始droplet库。
