# ADR-0004: V7 CoVarNet主分析用K=9，不用秩调查规则选出的K=4

- 日期：2026-11-05（UTC+8）
- 状态：accepted_for_V5_V7_comparison；生物学结论须在K4下复核
- 相关：[运行记录](../runs/20261103_V7_CM_blisa_v1.md)、[报告](../docs/reports/20261103_V7_CM_blisa/README.md)

## 背景

V7重算的主分支（1,207样本×47节点）和legacy全显示分支（1,303×181）都做了2–20秩调查（nsNMF，nrun 30）。

已观察：

- 主分支cophenetic在K4达峰（0.896），K5降到0.858，此后在0.82–0.87波动，K17–20又回升到0.85–0.87。
- legacy分支从K2（0.995）起单调下降，第一次下降超过0.02在K4→K5。
- 按驱动脚本的规则（第一次cophenetic下降超过0.02），两个分支都选K4。
- RSS随K平滑下降，没有拐点。

## 决定

本轮主分析固定K=9，K4作为敏感性分析。不宣称K9是最优秩。

## 依据

1. **目的是受控比较。** 本轮要回答“注释从V5换到V7后，模块怎样变化”。V5（以及v7broad、20261010）都用K9。如果同时换K，注释变化和分辨率变化会混在一起，无法归因。
2. **“最优秩”的证据弱。** 主分支在整个2–20范围内cophenetic只差0.08，且不单调；legacy分支在K2最高、随后单调下降，这是cophenetic偏好小K的已知倾向，规则基本是在选第一个下降点之前的最小K。RSS没有拐点，因此也给不出另一个候选。
3. **K4太粗。** 已观察：K4的4个模块跨seed非常稳定，但混合了多个谱系；K9中“myCAF＋恶性上皮＋内皮”这一模块（对应V5 CM07）在K4中不是独立模块。用K4会失去与V5逐模块对齐的能力。
4. **K9本身可复现。** 7/9个模块跨seed稳定（W列相关0.87–0.99）。留一来源和来源等权的结果见运行记录。

## 后果

- 报告的所有V7模块都要附注“K9为比较分辨率”。
- 任何生物学结论都要说明它在K4中落到哪个父模块；若在K4下消失，应写成依赖分辨率。
- 若以后要选一个“最终”秩，应改用不偏向小K的准则（例如留一来源的模块复现率、分辨率间的嵌套稳定性），不再只依赖cophenetic下降规则。
