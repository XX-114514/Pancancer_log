# ADR-0003: Codex Cloud代码开发与服务器计算

- 日期：2026-10-11（UTC+8）
- 状态：accepted_by_user；Cloud环境发布仍待用户操作
- 授权：用户明确选择Codex云端任务，并要求以Pancancer_log整理状态、commit和push。

## 决定

沿用已有Git历史，将公开的Pancancer_log作为代码与项目控制仓库。Cloud处理轻量可审阅开发，服务器持有数据并执行全量分析；用固定commit、运行合同和脱敏审计摘要连接两端。

## 依据

当前下载源数据超过500万细胞；既有权威基线467万细胞。矩阵、患者行、实际技能与长任务在服务器，无法从GitHub快照自行重算或推断临床结果。仓库保留历史发布边界；用户希望通过Cloud继续开发。

## 后果与验收

新增零额外Python依赖的导出/报告/校验工具、离线合同测试、云端首任务和同步流程。公开内容仅来源级汇总及逻辑路径，患者映射留在服务器。下载前处理继续；跨研究整合、身份/CNV晋升和临床发现各自通过门槛。Cloud环境创建与Publish不等同于本次仓库交付，必须单独记录成功执行证据。
