# 为什么当前CM还没有形成CoVarNet式的生物学发现

2026-10-31。比较对象是20261030新TME与CoVarNet原论文；旧20261014免疫CM02的临床结果不计作新CM证据。本次是已有结果的诊断与改进设计，没有执行新的注释、rank选择或临床模型。用户已明确要求本报告及相关报告同步GitHub。

**判断：问题同时涉及节点定义、有效样本设计和验证链，但目前不能定量归因“多少由注释、多少由输入造成”。** 数据量不小，算法也确实产生了重复性较好的组成因子；尚缺的是可解释且跨情境成立的生态关系，以及它们与独立组织/临床问题的连接。不能把尚未形成论文发现说成完全没有有价值的信号。

## 1. 我们与原项目实际在做不同难度的问题

| 环节 | CoVarNet论文设置 | 本项目当前设置及影响 |
|---|---|---|
| 生物学参照 | 健康组织为参照，比较癌症中的重塑 | 当前发现主范围为合格肿瘤材料，缺乏同口径健康/癌旁对照；无法直接复现其进展叙事 |
| 节点定义 | 91个非上皮参考亚群，含15个癌症相关亚群；TOSICA迁移 | 主要为参考身份×数字cluster；非免疫节点仍多为数字群，生态角色不清楚 |
| 材料条件 | 主要为新鲜、未富集10x scRNA | 已有来源资格v7，但治疗阶段、物理材料/患者与制备背景仍不完整 |
| 实际拟合样本 | 泛癌矩阵955个样本 | 本项目T/NK–髓系628工作单位，六谱系仅241；单位不能直接视为独立患者 |
| 比例 | 各亚群在相应父类型内的比例 | 同样采用父类内比例，但父类本体是否逐项对齐尚未复核；不同分母定义不同问题 |
| 参数 | 通用Methods调查K=2–20；泛癌候选成员top15 | 当前K=2–12、首次cophenetic下降启发式、top10、候选块加权，是项目变体 |
| 解释与验证 | 组成、组织情境、空间和协调表达衔接，另检验独立病变结局 | 新CM尚未接上合格临床终点或完整外部测量；不能借用旧CM结果 |

论文依据：[Methods、Fig.5及补充入口](https://pmc.ncbi.nlm.nih.gov/articles/PMC12240829/)；实现依据：[作者代码](https://github.com/QiangShiPKU/CoVarNet/blob/main/R/CoVarNet.R)。原论文设置不意味着所有CM都已成为临床标志物。公开论文展示的是完成解释与验证后的结果，而我们正在审阅包含空网络、重复和未决项的完整探索目录，两者不能用“漂亮模块的数量”直接衡量。

## 2. 注释确实是瓶颈，但问题不只是分类器准确率

### 节点尚未成为可以解释的细胞亚群

当前canonical身份把部分状态化参考标签归并为保守身份，这有利于避免把“cytotoxic”误当CD8身份；但归并后的节点可能过宽。同一Treg相关身份又被数字cluster拆分成多节点，网络便可能首先捕获这些划分之间的比例关系。需要证明每个交集节点有独立的marker、跨来源表达一致性与实际材料覆盖，不能靠父群marker借名。

基质和内皮尤其明显：主六谱系模块使用基质cluster5和内皮cluster22，当前不能据此直接命名CAF、周细胞、血管生成或淋巴内皮。不是改一个名称就能解决，必须核查节点自身表达及参考适用性。

### 已做五种方案，不等于已排除注释问题

五种方案主要改变免疫参考视图，非免疫部分共享数字cluster。它们没有充分检验“更好的基质/血管细分能否产生可解释模块”。SingleR是在来源×群表达上提议，CellTypist主参考是逐细胞推断；比较还混合了参考覆盖、聚合和粒度差异。

已有同材料、common-K4的CT canonical与HPCA匹配，6个成功配对的有效基底余弦中位数约0.715，活动相关中位数仅0.090，另两侧各2项未匹配。这说明表示方案明显影响模块活动；**不能由此判定哪种标签更真实，更不能把全部差异算成注释错误率。**

改进重点应是“参考亚群内容＋分层节点证据”，而不是把CellTypist换成TOSICA就期待论文式结果。参考中没有合适肿瘤亚群、非免疫参考不完整或cluster划分不合理，换分类器仍然无解。

## 3. 输入问题主要是有效设计，而非细胞总量

新TME共同范围有2,758,214细胞，但重复观察单位、同癌种独立来源、捕获完整性决定可识别的生态关系。六谱系完整覆盖要求只留下241工作单位；36来源进入该面板，而基质—内皮边仅6来源达到本轮≥10工作单位的来源内估计门槛。

现有工作单位表中457项治疗阶段精确记为“待核实”，另有其他未知编码。将这些材料与治疗前、治疗后、原发和转移材料混合，会让无法解释的背景差异参与NMF。来源与癌种高度耦合时，加入来源协变量也不能凭空区分二者。

本轮四个CT主面板的来源η²约0.284、0.548、0.540、0.654。它们是样本内描述性分组解释度，不是“28%–65%由批次造成”。来源等权后的common-K4 CT身份有效基底余弦约0.920，但活动相关约0.514；同细胞预算敏感性中的活动相关约0.472。**主题可以保持，病例排序却改变**，这对后续临床用途很关键。上述指标来自不同对照，不能相加作归因。

输入改进优先于继续扩充总细胞数：补足同癌种可比来源、确认独立患者与材料、明确治疗阶段和捕获方式。富集材料用于适合的谱系内状态，不能通过缺失填零变成完整TME。更严门槛会提高可比性，也会牺牲稀有群和样本量；需要报告覆盖损失，而不是无限加严后期待更多网络。

## 4. 当前算法路径还有哪些可核查的差异

项目执行了真实作者nsNMF/网络流程，并完成数值审计；但这不等于原论文实验配置的完整复现。当前R执行器的rank规则是首次超过0.02的cophenetic下降前一阶，否则取上界；论文Methods给出的是另一套局部峰规则。四个canonical主面板均选K2，可能压缩细结构，但**尚未证明K2选择错误**。单纯把最大K从12提高到20也不直接解决首次下降选择K2的问题。

top_n既决定候选成员，也影响作者的特异性阈值；top10改top15不是一个纯粹“多看五个成员”的操作。候选块加权改变了分解目标，而当前边相关另行计算；需在基准分支明确匹配这些设定。psych版本下作者兼容P值行为与原始Pearson/BH分支已经单列，不能把网络稀疏一概归咎于多重校正，也不能为得到好看网络选择更宽松分支。

主面板K2归一化活动满足H1+H2=1，两个相反临床方向只是一项组成对比。六谱系CM01又由Treg内部和基质—内皮两个不连通部分组成，CM02重复后者。它们需要在因子、连通分量和重复边三个层面解释，不能直接视为两个独立生态系统。

## 5. 哪个原因更值得先改

| 判断 | 当前证据 | 优先动作 |
|---|---|---|
| 注释/节点定义影响大 | 同域同K表示方案的活动一致性弱；非免疫仍为共享数字群 | 优先做髓系、基质、内皮和T细胞关键亚群的本节点marker与来源一致性审查 |
| 样本设计影响大 | 完整面板缩至241；来源等权改变活动；治疗/单位不完备 | 在同癌种、同材料、同阶段构建至少两个可比来源的主分析范围 |
| 算法配置可能压缩或改变模块 | rank启发式、top_n、加权和参考代码配置不完全同口径 | 在同一冻结输入上作论文配置基准，保留当前变体；不以临床P值择优 |
| 验证链是临床价值的直接短板 | 新CM尚无合格终点连接，现成疗效队列不在43来源内 | 先冻结可迁移测量和患者桥，再做完整临床家族 |
| 细胞量不足是首要原因 | 目前无此证据 | 不把继续堆细胞或重复跑NMF作为首要动作 |

以上是按证据和依赖排序，不是已完成的因果归因。没有受控实验，不能断言“主要都是注释”或给出两类问题的贡献百分比。

## 6. 建议怎样改：有限、可检验的下一轮

**A. 建立一个能回答明确问题的主范围。** 从同癌种至少两个来源、采样/治疗阶段可核、患者与材料可连接的集合中选择首个可行范围。选择依据是覆盖和设计，先不看CM临床效应。全43来源继续作为广泛探索与迁移范围。若没有这样的癌种，首要工作就是补资料/合适队列，不能靠模型调整替代。

**B. 优先形成非上皮免疫—基质—血管参照。** 暂不要求上皮也在每个材料充分捕获。建立稳定父类和有限细亚群，对每节点输出原生marker、反marker、来源一致性、捕获与缺测状态。接受不了细身份的节点留未知，不删除父分母。T细胞状态标签可以作为功能节点的独立视图，但不得自动当成CD4/CD8/TCR身份。恶性上皮程序在第二阶段作为情境变量或独立层加入，不为追求“全TME”提前增加覆盖损失。

**C. 先做注释×输入的受控对照，再决定扩大计算。**

| 因素 | 水平1 | 水平2 |
|---|---|---|
| 节点 | 当前参考×cluster | 经本节点证据支持的分层亚群 |
| 输入设计 | 当前广泛合格材料 | 可比癌种/阶段/捕获设计及预设平衡权重 |

每个输入水平内，两套节点必须使用共同细胞、相同材料和同一分母；输入水平之间在共同材料桥上评价可比结果，另报材料纳入/排除造成的范围变化。平衡权重可以在同一单位集合内做严格对照；严格子集则改变目标人群，不能把结果差异全部当因果贡献。缺少某一格时如实不可比较，不伪造四格。

先固定同K、同算法参数比较节点和输入；另做完整预设rank/top_n敏感性，避免把参数差异混进注释效应。已有旧资格×旧标签对照可补充历史诊断，但不能替代上述可解释新节点实验。

**D. 设置成功标准，允许得到“未发现”。** 评估节点表达可解释性、来源内跨谱系边方向及效应区间、来源留出恢复、细胞预算扰动、连通结构及重复网络。为完整预设家族报告置信区间和多重比较；发现后挑出的边的描述区间不叫确证。按患者/来源划分而非随机细胞留出，保留绝对预测性能和负结果。网络更多、K更大、UMAP更漂亮都不是成功标准。

**E. 冻结组成CM后接状态和临床。** 先检查CM关联是否仅来自父群比例、RNA深度或一般增殖/炎症；再在可信身份内部测量旧免疫五轴或预定义程序。保留原定义并统一测量方法，不把814候选当814正式状态。重叠研究只作解释，来源不重叠也还须核患者复用。最后比较临床背景、组成、CM、状态及其组合的患者/来源外增量。来源富集T细胞时不投影完整髓系/基质CM；bulk只能先建立并校准新CM表达代理。

## 7. 执行边界与交付

本轮完成论文/实现对照、已有对照结果复核、瓶颈分级和新实验设计；没有重跑或更改已冻结科学发现。上一轮的全部25拟合/240记录/288边审查见[研究报告](TME_CM_review.md)与[完整成员目录](all_CM_catalogue.md)。新临床价值尚未建立，当前最合理的工作不是再无约束扩大模型搜索，而是完成一个设计清晰、细亚群可信、能外部检验的生物学问题。

公开附件仅含汇总和技术记录，不含患者行、细胞/表达矩阵、学习权重或原始基因资源。证据SHA与统计口径见[汇总收据](evidence_summary.json)。
