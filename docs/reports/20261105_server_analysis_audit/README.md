## 3. 数据扩展、恶性判定及TME范围

### 3.1 三个数据版本不可混用

历史0906发现集为54 GSE、4,676,787细胞、1,322原始样本；其CoVarNet实际输入为1,303样本。2026-11扩展集`integration_v2`为72来源、4,720,931细胞；本次V7 CM重算仍来自历史0906细胞宇宙，**不是在扩展472万细胞上重发现**。

分析就绪v1有53来源、3,818,042细胞、94,200基因，X为原始计数，附来源测量mask。integration_v2统一decontX后为72来源、99,071基因，全部来源共有12,563基因；X为校正计数的CP10K+log1p，另留原始counts和decontX层。未测基因的结构性0不能直接当生物学0。

详细配方、来源筛选和旧技术验证见[analysis-ready v1](../../ANALYSIS_READY_ZARR_V1.md)、[integration_v2](../../INTEGRATION_V2.md)。早期“无注释”描述是该数据层本身的状态；后续恶性侧表和候选标签不能静默当作已附加的最终身份。

### 3.2 恶性与TME的集合关系

统一恶性worker按单位先用marker判候选/参考，再运行scATOMIC 2.0.3与inferCNV 1.18.1；scATOMIC肿瘤占比≥50%的原免疫/基质群改为候选，同单位参考不足时向同来源借参考。CNV score或corr群中位数高于对照99分位视为CNV阳性。两法一致才作明确恶性/非恶性；冲突或不可评估保留uncertain。详见[方法](../../MALIGNANCY_TME_V1.md)。

原run_v1汇总为3,383,398 TME细胞，其中3,015,706 non_malignant、367,692 uncertain，71来源、1,211单位、978来源内患者键、101簇。后来按用户已决定范围排除GSE182434分选来源及GSE189357的3个AIS单位；原对象通过标记排除，保留历史细胞，所以“对象行数”与“当前合格TME总数”不再相等。

最新已入库范围表为3,347,659 TME细胞，CoVarNet v1可用2,980,723。uncertain留在TME探索图中，但不进当前CoVarNet v1主集合。**包含在图中、非恶性、可进CM，是三个不同条件。** run_v2使用同一排除表物理重建，不应用原对象行数检验当前范围。

本次查见72个恶性最终侧表均已存在；这更新了11-03候选注释计划中的“四来源等待侧表”，但未逐细胞重验72个文件，不能只凭存在判全部成功。新TME日志明确矩阵为3,347,659×4,000，已完成PCA和来源θ2 Harmony；未查见`run_v2/report/tme_summary.json`，调度器状态不可查，因此只记“生产进度可见、最终验收待补”。见[进度摘录](../../../inventories/server_analysis/2026-11-05/tme_run_v2_progress.json)。

## 4. 注释证据：V5/V7与新TME候选流程

### 4.1 V5/V7的确切变化

V5、V7有相同细胞宇宙，但大类同名标签改变770,833（16.4821%）。Unknown+Ambiguous从846,526降至129,843；其中相当一部分转为边界或provisional，不能把减少量当新增严格身份。V7严格大类4,057,641（86.76%），严格亚型2,455,424（52.50%），未解决亚型仍接近一半。

恶性主标签同名改变1,053,571（22.5277%），其中61,525是旧non_malignant到cnv_no_malignancy_detected的语义保持，不能全称纠错。恶性数量由679,957变515,031；旧恶性390,245仍恶性、142,415转not_candidate、138,410转uncertain。这包含候选池及CNV重跑两种影响，聚合交叉表不能分离因果贡献。

V7细分标签“数量相同”不能证明逐细胞相同。现有[完整聚合表](../../../inventories/server_analysis/2026-11-05/tables/v5_v7/)支持上述计数，不替代逐细胞V5×V7细分流向；历史CM每个成员的流入/流出仍待补。

### 4.2 参考预测与最终身份分开

早期1,000细胞GSE138709试点中，CellTypist 1.7.1两个Immune_All模型均成功，特征交集5,034/6,639。它只是运行与ID/分数读回试点；之后marker分流方案取代“对全部细胞套免疫模型”的准备方案。

分流依据是单位内快速群的原表达marker均值：父类均值≥1、领先第二父类≥0.25、至少2个marker均值≥0.5；不足2个实测marker的panel不能获胜。免疫走Immune_All High/Low，内皮/周细胞走Adult_Human_Vascular，成纤维/上皮/肝/胶质走SingleR HPCA，缺合适参考则未解决；恶性细胞排除，uncertain独立保留。

GSE138709全来源v2共11,381细胞：7,175恶性排除，2,421免疫、299血管、1,139 HPCA、347无兼容参考；这些合计为4,206 TME候选。候选通过/冲突状态按原JSON保留，[摘要](../../../inventories/server_analysis/2026-11-05/annotation_pilots.json)中`accepted_fine_identity=false`。HPCA参考矩阵713列而colData无行名，仅依赖配对缓存顺序，未建立独立sample-ID对齐；HPCA组织特异成纤维标签不能证明CAF亚型。High/Low相关模型也不是两份独立验证。

历史preflight为67待提交、1个可复用、4个等待恶性。现在侧表存在情况已变化，必须重新预检；未发现全量候选注释完成的收据，不因代码、计划或调度依赖准备好就称“全量注释完成”。新归档保留7个合成编排/收集测试及真实来源检查入口。

## 6. NMF比较与本次代码审计新增发现

### 6.1 既有比较

45份`info.json`覆盖9方法×5seed，全部K9。共享频率输入为47节点×1,207样本；X组以父类内频率作节点min–max。另设log1pNMF_counts、cNMF_counts，使用节点原始细胞计数；cNMF_X仍有自身方差预处理，LIGER按来源拆14个数据集且未做后续quantile normalization，所以这些分支不全是“仅替换优化器”。

### 6.2 新发现：比较指标不具备等价缩放不变性

代码先将W按节点行归一，再计算列余弦并匈牙利匹配。但是NMF的W×D、D⁻¹×H与原拟合等价，行归一不能消除因子列尺度。不同包的因子尺度约定可能影响匹配，不能因为“行归一”就宣称已经统一所有方法尺度。

本次仅读取既有45个小W表，先将W列和规范为1再做同一行归一/匹配，并对等价W列乘10⁻²～10²进行反例核验。原指标同模型的等价缩放余弦降到约0.65–0.89；规范后全部为1。原/规范平均参考余弦变化：RcppML 0.7248→0.7496，cNMF_X 0.5426→0.5307，sklearn Fro 0.6656→0.6614；sklearn Fro的5个seed均有因子匹配变化，LIGER及log1pNMF各1个seed变化。

原跨seed稳定性趋势大体保留：nsNMF约0.723，RcppML/CoGAPS接近1，Fro规范后接近1。因此“稳定性不同”有支持，但具体模块跨方法归属与H相关应在固定尺度后重核。**没有重新拟合模型，也没有以该敏感性表替换原始运行结果。** [原表](../../../inventories/server_analysis/2026-11-05/tables/nmf/method_summary.tsv)、[尺度敏感性表](../../../inventories/server_analysis/2026-11-05/nmf_scale_sensitivity.tsv)、[可复现审计脚本](../../../scripts/server_audit/check_nmf_scaling.py)。

其他边界：nsNMF采用KL＋平滑，Frobenius方法不同，两者同时改变，现有实验不能把差异独立归因给某一项；计数组输入语义不同，接近置换零分布不等于“算法差”；原节点置换零分布未按谱系/来源结构保留，只是该相似度的粗参照。K9、5seed、来源结构和未独立验证限制仍在。
