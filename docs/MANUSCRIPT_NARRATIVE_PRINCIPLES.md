# 论文叙事原则

用户于2026-10-23明确要求后续论文写作遵守“发布会原则”。本文件约束论文组织与表达；运行日志、完整结果和证据记录继续按原规则保留。

1. 以最有支撑的优势确立核心主张，围绕一条生物学问题组织正文。
2. 结果按论证顺序展开，不按实施、版本、算法尝试或故障时间线写。
3. 用精确的研究对象和作用域表达结论，删去无论证职责的自我削弱措辞；必要测量定义与条件放在对应主张旁。
4. 评价维度服务研究目标。明确比较对象、分母、时点和统计量；不同口径各自标明，预设检验与结果后形成的新问题分别记录。
5. 根据目标差异及合理权衡解释结果，不建立与研究主张无关的排名比赛。
6. 每个主要优势主动写出：解决了什么问题、得到什么结果、对理解生物学有何推进。
7. 每项主文实验、每张主图承担明确论证职责。过程记录归日志，完整预定比较和必要对照归方法及补充材料；不改写或删除已有证据。
8. 摘要和引言按“问题—缺口—思路—最硬结果”组织。计算方法按所承担的问题介绍，不以软件列表替代研究思路。
9. 结论强化核心记忆点，与摘要及主要结果使用一致的测量对象和结论强度。

## 主张与证据对应

组成模块、RNA功能评分、蛋白相对状态、空间邻域和临床终点分别命名；同一篇论文可以整合这些层次，但相同编号或生物学主题不代替测量对应。观察性关联使用“关联、富集、组织、共同变化”等适合其证据的动词；机制和治疗预测各由相应设计支持。

实际科学数字、候选优先级和稿件正文在获准私有工作区/对话保存；公共日志记录写作要求、审阅范围、版本和技术指纹。正文排版不改变原模型、正式注释或已闭检验家族。
