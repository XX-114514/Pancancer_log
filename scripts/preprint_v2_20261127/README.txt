Anatomical opening-figure renderer for externally supplied frozen atlas inputs.

python scripts/preprint_v2_20261127/render_figure1.py --atlas-dir "$ATLAS_DIR" --node-map "$NODE_MAPPING_TSV" --registry "$SOURCE_REGISTRY_TSV" --resources-json "$RESOURCE_CONFIGURATION_JSON" --output "$NEW_OUTPUT"

Python 3.12, NumPy, pandas and matplotlib. Coordinates are never refitted or sampled. Anatomy is an original vector schematic. All scientific inputs, figures, manuscripts, captions and supplementary tables remain external to public Git. The private bilingual assembly script is intentionally not published here because it contains manuscript text.
