# Communication evidence chain release

This manuscript-facing snapshot was assembled on 2026-09-06. It contains final
narrative reports, summary evidence tables and publication figures for the
CM-to-communication-to-spatial-to-clinical chain.

Important scope boundary: these outputs reuse the frozen V5 malignancy, CoVarNet
and LIANA branch. V7 is the current annotation/CNV reference, but this
communication release has not been recomputed on V7.

Included:

- `reports/`: detailed report and evidence-chain summary;
- `tables/`: focus-axis definitions, replication summary, collagen-DDR sweep and
  evidence matrix;
- `figures/`: PDF vector figures and PNG review copies.

Excluded are raw/cell-level CosMx tables, patient-level matrices, full LIANA
events and source scripts with workstation-specific paths. Those scripts remain
in the analysis workspace and are indexed in `source_code_manifest.tsv`.

For Prism, prefer PDF for assembly and PNG for rapid review. Keep the source-table
and figure basename together when preparing supplementary panels.
