# V7 release data review

Review date: 2026-09-06.

The tracked V7 tables are aggregate or sample-level method summaries. Inspected
sample-level columns contain public-study GSE/GSM accession-derived labels, cancer
type, candidate policy, cell counts, method status and CNV summary statistics.

The release does not contain patient names, contact details, dates of birth,
clinical outcomes, treatment histories, raw expression matrices or cell-level
metadata. The sample strings are study pseudonyms inherited from public source
datasets, not a new identity mapping.

This review supports use in the confirmed private Pancancer_log repository and as
a candidate supplementary package. Before any public release, confirm source-data
licensing and journal requirements for reproducing public sample labels.
