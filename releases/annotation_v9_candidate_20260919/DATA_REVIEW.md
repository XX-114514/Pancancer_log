# Data and privacy review

This candidate snapshot contains one aggregate Markdown report, one aggregate
15-row review template, release metadata and a checksum index.

- No cell-level annotation table, expression matrix, H5AD/RDS/pickle/Zarr object,
  raw sequencing data, source code tree or complete runtime log is included.
- Targeted scans found no credential-like strings, direct patient identifiers or
  literal internal absolute server paths in the copied report/template.
- The original V9 freeze manifest is not copied because 78 source-hash keys expose
  internal absolute paths. It remains external and is represented only by logical
  path, byte size and SHA-256.
- The template is explicitly unfinished and must not be presented as reviewed or
  finalized annotation.

Private GitHub storage does not change these minimum-disclosure rules.
